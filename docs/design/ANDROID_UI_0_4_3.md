# 听野 0.4.3 视觉与交互约定

日期：2026-10-07。版本：0.4.3 / versionCode 20。沿用听野品牌与原生 Android Java/View；0.4.2 留作对照。

## 设计方向

温暖、清晰、精确的游戏感知工具。保留现有听野 Logo、暖白页面和深青操作色。游戏选择保留原版熟悉的左右卡片构图；两款入口的动作都写「开始辅助」，适配状态独立显示「当前可用／体验版」。消消乐副标题为「休闲益智辅助」，去掉「· 乐元素」。文字放不下时转为上下布局，不压缩文字。

[Awwwards](https://www.awwwards.com/about-evaluation/)、[FWA](https://thefwa.com/) 和 [CSS Design Awards](https://www.cssdesignawards.com/) 作为构图、细节、品牌与交互完成度的参照。这些机构的奖项没有为本应用评审；本轮不生成获奖资格或设计评分。

方向弧线仅为静态品牌图形，位于游戏入口和运行状态区域；它不表达方向、敌人位置、识别置信度或实时结果。游戏中的装饰不做循环动画。

## 页面层级

- 游戏选择：品牌 → 选择游戏 → 两款入口 → 更新 → 社区标记。状态与动作分别表达；「开始辅助」在游戏入口执行进入该游戏辅助页面，运行主页再处理学习和系统授权。
- 王者主页：品牌与游戏 → 运行状态 → 开始辅助／停止 → 设置／返回游戏选择。运行状态与开始操作在 360×800dp、普通字号首屏可见。设置与切换为导航行。
- 设置：授权与运行、提醒与学习、实验与反馈。每一行保留名称、短摘要和箭头；没有重复的大 Logo 或页尾大返回按钮。
- 配置：字段标签、当前值、开关／滑杆分层；呈现层实验从助手页移至配置页，保留原偏好键值。助手页集中处理语音、画面及上传同意，助手继续默认关闭。
- 反馈：说明、记录选项、导出和删除分开；删除离导出至少 24dp。问题输入、阅读位置和已展开的隐私说明在旋转及返回时保留。
- 消消乐：统一返回栏、字段和操作层级；判定自测仍只属于消消乐，不进入王者设置。

## 上下文说明与学习

问号一次点击打开对应分组。手机用底部面板，宽屏仅在还能为设置保留至少 360dp 时使用 360～420dp 侧栏。标题、关闭按钮固定，正文独立滚动；切组直接换内容，关闭回到最后触发入口。

原说明的名称、内容与顺序保留。按自然段或句群分段，以行距、段间距和字重减轻阅读压力；没有重复的「查看完整说明」跳转，也不会自动播放说明或改变偏好。

完整提醒说明首次提供自动学习，但不锁定开始。顶部明确显示“跳过并开始”，底部固定区同时保留该操作；开始流程中的底部操作为播放／暂停与跳过开始，不再叠加停止按钮。听完后开始操作改为“开始辅助”。跳过立即取消声音与旧回调并进入必要授权，单独记录跳过状态，不记为完成学习；听完或跳过后默认直接开始，开启“每次开始前重听完整说明”时仍展示且仍可跳过。

可选一段收听，也可暂停和继续。底部区显示当前说明与进度；短横屏将状态与操作并排，长状态信息可独立滚动，为正文保留阅读空间。后台、旋转或返回时释放播放资源，记录未完成句子；用户点击继续后从该句开始，不自动续播。更换输出配置导致说明步骤变化时丢弃不匹配的旧位置。停止、换段、跳过或新轮次取消旧回调，旧回调不能推进当前播放。

## 状态、焦点与动效

加载、完成、失败、不可用与禁用使用文字配合标记和样式；静态状态重复刷新不重复更新读屏文字。图标有中文操作名称；装饰不进入无障碍焦点。导航行以整体按钮语义呈现，避免标题与摘要成为重复操作焦点。

助手收起时保留36dp白点视觉，触区为56dp；展开面板不透明，避免正文与控件对比度随游戏画面变化。

原生点击反馈。帮助面板展开／收起为 220ms、12dp 位移及淡入淡出。系统关闭动画时直接到最终位置；页面隐藏时取消动画。快速关闭并重新打开不会被旧结束回调隐藏。

弹窗重排复用原有原生按钮和回调，不复制点击逻辑；保留系统按钮区标识，以实际重排高度预留操作区，长说明在剩余空间滚动，确认／取消始终完整可见。输入与滚动在布局完成后恢复，避免光标把页面拉到输入框底部；密码与密钥字段不进入通用 UI 状态保存。
