# 视野记忆

视野记忆帮助玩家保留已在小地图中出现的信息，减少持续寻找和记忆的负担。

## 状态与关联

系统按帧关联已识别标记，记录可见状态、最近位置、观察时间及可确认的移动方向。新的观察更新同一轨迹；目标消失后，最后观察与当前可见信息分别表达。

记忆不代表目标仍在原地，也不用于推断草丛、战争迷雾或画面外的隐藏状态。过时、歧义或低置信度的观察不会当作新事实提醒。

## 与提醒的关系

- 多帧确认减少短暂误识别。
- 相对位置用于可确认的方位与附近敌人提示。
- 持续占用、重复事件与冷却由输出调度统一处理。
- 暂停辅助、采集失效或切换场景时重置相应状态，避免旧信息沿用。

声音、语音、振动及视觉提示遵循玩家已保存的设置。游戏判断和操作始终由玩家完成。

实现入口为 `native/` 中的感知记忆与关联逻辑，以及 Android 的 `CaptureService`、`CueArbiter` 等组件。
