# 视野记忆（Vision Memory）

## 产品定义

视野记忆不是敌方追踪或战术指挥。它把玩家本来能够看见、但可能无法持续观察或记住的小地图事件，重新编码成高对比视觉、简短语音和触觉线索。

第一版明确不提供兵线计时、路线推荐、打龙建议和全局“注意敌方打野”等策略判断。

主画面边缘的红色候选和困难负样本只作诊断，不能当作 `enemy hero` 真值；小兵、野怪可能有相似血条，镜头也可能漂移。160 张复核批次已完成人工复核（47 张 `corrected`、113 张 `negative`、114 个框），审计文件为 `data/private/main-edge-review-v1/review-batch-v1/review-completion-audit.json`。主画面边缘分支默认关闭，发布版不启用。

## 事件状态机

```text
候选目标
   │ 连续三帧中至少命中两帧
   ▼
APPEAR ──持续检测──▶ TRACK
   │ 连续丢失三帧
   ▼
                    DISAPPEAR
                         │
                         ├─ 保存最后位置
                         ├─ 保存可靠的最后移动方向
                         └─ LAST_DIRECTION 残影保留 4 秒后清除
```

4 秒计时从确认进入 `DISAPPEAR` 时开始；在确认丢失前的短暂漏检不会提前消耗残影时间。

识别器保留原有身份宽限：进入DISAPPEAR后两秒内返回沿用轨迹ID，不产生新的APPEAR；至少两秒后返回重新确认并分配新ID；四秒残影到期后清除。双类近区提醒独立于该APPEAR宽限。LOST只说明检测缺席；目前可靠缺席连续3秒且至少3个快照才确认消失，短漏检或邻近换号保留提醒状态。确认后返回近区仍需新的2/3识别确认，之后不另加冷却。

采样中断、屏幕旋转或暂停会直接重置状态，不把技术中断误报成“敌人消失”。
自适应小地图定位器无法确认可用区域时，也会静默清除小地图轨迹；定位恢复后重新确认目标，避免把定位失败误认为目标消失。

## 信息输出

| 事件 | 视觉 | 听觉 | 触觉 |
| --- | --- | --- | --- |
| APPEAR | 红色高对比圆环 | 标准模式一次中性短音；详细模式可选无方向短语音 | 标准模式关闭 |
| TRACK | 跟随当前头像 | 静默 | 静默 |
| DISAPPEAR | 最后位置、斜线与移动箭头 | 静默 | 静默 |
| LAST_DIRECTION | 4 秒内逐渐淡出 | 静默 | 静默 |

提示层不接收触控，并设置安全窗口标记以请求系统从截屏内容中排除；不同设备上的实际行为仍需真机确认。新安装默认启用新头像事件提醒；画面提示只有在用户授予 Android 悬浮窗权限后才会显示，声音和触觉仍可独立使用，提醒也可在设置中关闭。

## 当前相关性过滤

第一版只使用已经可靠获得的证据，不伪造“完整战场理解”：

- 视觉事件必须通过置信度门限和 `2/3` 帧确认。
- 小地图只在稳定 APPEAR 时产生声音候选，会话级最短间隔为 15 秒；同一稳定目标保持 30 秒不得重复提示。
- 玩家位置不可靠时只播放中性短音，不把小地图中心方向误当成相对玩家方向。
- 标准模式不使用小地图语音和触觉；详细模式以后可播报“发现新的敌方头像”，仍不猜方位。
- TRACK 和残影刷新永远不重复播报。

以上规则针对320单类基线。双类近区profile能识别自身小地图标记，另有独立近区事件：敌方标记进入附近时按8向小地图方位提示，按轨迹连续可见状态去重；连续可靠缺席3秒确认消失后再在近区出现，其他目标仍在附近也不拦截。返回需新的2/3识别，同帧确认的新目标合并，方位和距离只取本次新目标；持续可见的目标仅进出范围不重播，REARM仅表示出范围时仍持有提醒状态。短漏检和短暂定位失效后的邻近编号重建保持原提醒状态，不把技术恢复当成游戏消失。该路径不叠加15秒全局冷却，标准模式不再播放远处新头像中性音。近区以自身小地图标记为原点，与主镜头无关；轨迹ID不是英雄身份，文案不说“危险”或“安全”。规格见`docs/plans/黑客松方案收敛与实施路线.md`第4节。

“危险接近”以及主画面边缘英雄提示需要先通过上下文英雄分类和玩家相关性门。镜头跟随以 250 ms 内更新、处于中央跟随带的 `player_screen_anchor` 为主要证据，小地图玩家位置 500 ms 内更新时只作辅助。没有可靠的敌方英雄类别、玩家屏幕锚点、HUD、存活状态、敌我接近、外围视野或镜头关系时，系统不得仅因检测到红色血条、敌方英雄或打野就发出提醒；立即清除主画面 track 并静默，小地图记忆继续运行。全部证据通过后仍需执行 `2/3` 帧确认，并交由统一 `CueArbiter` 决定是否输出。后续完整相关性评分至少需要：

```text
relevance = 距离 × 接近速度 × 危险区域 × 交战状态 × 用户偏好 × 新鲜度
```

任一关键输入缺失时应降级为视觉记忆或保持静默，而不是用固定规则猜测。

## MVP 边界

| 能力 | 当前状态 |
| --- | --- |
| 敌人出现 | 已接入实验视觉、空间声音和触觉通道 |
| 敌人消失 | 已接入最后位置和移动方向残影；标准模式静默 |
| 附近敌人（出现/再次出现） | 双类实验profile中已实现；连续可见去重，确认消失后返回重新确认并提示，同帧新目标合并；暂定R_enter=0.16／R_exit=0.20待独立标定，3秒缺席确认及频率修订待新真机/目标玩家验证 |
| 危险接近 | 接近速度、危险区域和交战状态未实现，当前不播报 |
| 死亡／复活关键状态 | 软件链路已接入，真实签名与独立留出集待完成 |

移动端工程可行性、功耗、发热、帧率和端到端延迟均以听野自身的实体机测量为准。
