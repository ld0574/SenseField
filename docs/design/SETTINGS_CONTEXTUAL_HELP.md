# 设置页的分组上下文说明

2026-10-05 基线；2026-10-06 续改约定，适用于听野 Android 设置页。

## 2026-10-06 视觉续改约束

- `SettingHelpContent` 的文案、名称、顺序与显示条件保持字节级不变；本次只调整帮助面板视觉样式，并移除面板内重复的“查看完整说明”链接。
- 面板沿用白色卡片主题，圆角22dp、elevation 1。面板标题20sp；条目标题18sp加粗；正文18sp，并沿用既有阅读正文最多为系统字号150%的上限。
- 关闭按钮背景透明或半透明，灰色 X 图形20dp；触控区域保持56×56dp。
- 面板几何、滚动、返回行为及关闭后的焦点恢复保持既有约定。独立提醒指南、完整阅读页和试听／播放流程不受本次面板样式调整影响。

## 信息层次

1. 页面内的每个大分组保留标题和一句用途摘要，帮助入口紧邻标题。
2. 点击帮助，在原设置页面内查看当前组的详细说明；说明逐项使用页面上的名称与顺序。手机显示底部面板，宽屏显示右侧面板。
3. 提醒试听目录及其完整说明仍承担学习提醒的用途；帮助面板不再提供重复的“查看完整说明”链接。

页面不要给每个开关重复添加“说明”按钮，也不要将整组长文放进 Tooltip。只有独立且确实需要解释的专业字段才允许额外入口；本轮没有增加字段例外。

## 布局与交互

- 问号使用灰色圆形视觉，与标题保持约8dp间距，正常状态不使用链接蓝。图形与触控区域分开：图形较小，触控区至少56×56dp，并提供包含组名的读屏名称。
- 标题与可操作控件遵循系统字号，不裁字；长标题换行。长篇连续说明正文沿用150%系统字号上限，允许纵向滚动。
- 根据实际可用宽度选择布局。至少720dp时，右侧面板宽360～420dp，原设置保留至少360dp；更窄时改为底部面板。它们都为原页面保留可滚动、可操作的区域。
- 点击另一组的帮助直接替换当前面板，并从新组的开头阅读；不叠加窗口。面板打开与切组均不改变设置，不自动朗读，不触发试听。
- 打开手机底部面板时，将当前组移到上方设置区域，保留可见的标题和部分控件；用户仍能在该区域继续滚动。宽屏只在标题被裁切时调整原页位置。
- 返回键或关闭按钮收起面板，回到原页面；恢复最后触发入口的焦点。继续返回才离开设置页。
- 设置内容与帮助内容各自滚动。系统授权、同意对话框与试听按钮仍由用户主动操作。

## 本轮覆盖

配置与调参：提醒测试与语音、识别功能、提示方案、提示调节。

提示偏好：输出方式、事件提示。

助手设置：画面服务连接、连续语音与画面交互、呈现层实验。

触觉提醒：提醒节奏、震感档位、试听。

授权与运行：屏幕采集、运行通知、置顶视觉提示、后台省电策略。

布局回归不能替代真实低视力玩家的理解与操作验证；TalkBack实际焦点、放大后的阅读、手机震感和游戏适配继续单独记录。
