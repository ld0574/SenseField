## 一、基础小动物（6 种）

棋盘上的基本消除单位。任意横/竖 3 个同色相连即可消除。6 种颜色固定，低视力玩家主要靠**颜色**区分，其次靠动物轮廓。

### 小黄鸡（黄色）
- 外观：黄色圆形小鸡，6 种里最亮、最扎眼的一个
- 机制：基础三消单位；部分关卡中"收集 N 只小鸡"为过关目标（靠鸡蛋孵化，见第四节）
- 注意：不要和"鸡蛋/鸡窝"搞混——小黄鸡是成品收集物，鸡蛋是待孵化的障碍/机关

### 红狐狸（红色）
- 外观：红色/橙红色狐狸，尖耳朵长尾巴轮廓
- 机制：基础三消单位
- 注意：无

### 蓝河马（蓝色）
- 外观：蓝色河马，圆滚滚
- 机制：基础三消单位；早期关卡常作为收集目标（如"消除 N 只河马"）
- 注意：无

### 绿青蛙（绿色）
- 外观：绿色青蛙
- 机制：基础三消单位
- 注意：无

### 紫猫头鹰（紫色）
- 外观：紫色猫头鹰，大眼睛特征明显
- 机制：基础三消单位
- 注意：紫色在暗色背景下对比度可能偏低，播报时建议强调颜色词

### 棕色小动物（棕色）[待核实：物种疑为浣熊]
- 外观：棕色，第 6 种颜色
- 机制：基础三消单位
- 注意：物种名称未从可靠来源核实，暂按颜色"棕色"识别

## 二、特效

### 直线特效（横向 / 纵向）
- 外观：身上带横向或纵向条纹/箭头的小动物，条纹方向即消除方向
- 机制：
  - 生成：横向 4 连消 → 横向直线特效；纵向 4 连消 → 纵向直线特效
  - 触发：点击或与相邻动物交换，消除**整行**（横向）或**整列**（纵向）
- 注意：横/竖的区分对策略至关重要（打角落冰块要用横向），播报必须带方向

### 爆炸特效
- 外观：彩色闪烁的礼包/炸弹状特效动物
- 机制：
  - 生成：L 形或 T 形 5 连消
  - 触发：消除周围两圈范围（约 5×5 区域，两次爆炸）
- 注意：和普通 5 连（直线）生成的魔力鸟不要搞混——L/T 形才是爆炸，直线 5 连是魔力鸟

### 魔力鸟（俗称"彩虹"）
- 外观：彩虹色大鸟，全场最显眼，无法通过三消直接消除
- 机制：
  - 生成：直线 5 连消
  - 用法：与任意小动物**交换**，消除全屏该颜色动物；也可先点击魔力鸟再点击目标动物
- 注意：魔力鸟不参与普通三消；低视力玩家识别特征是"全屏唯一的大彩虹色块"

### 特效两两组合效果

| 组合 | 效果 | 核实状态 |
|---|---|---|
| 魔力鸟 + 普通动物 | 消除全屏该颜色 | 已核实（多篇关卡攻略一致） |
| 魔力鸟 + 魔力鸟 | 清屏（消除全屏所有动物） | 已核实（1584 关攻略："双魔力鸟互换后清屏消除"） |
| 魔力鸟 + 直线特效 | 结合释放，产生大量特效、大范围消除 | 部分核实（1168 关攻略提到结合，具体转化规则待核实）[待核实] |
| 魔力鸟 + 爆炸特效 | 大范围消除 | [待核实] |
| 直线 + 直线 | 十字形大范围消除 | [待核实]（品类通用规则，未找到开心消消乐专项来源） |
| 直线 + 爆炸 | 大范围十字爆炸 | [待核实]（同上） |

## 三、障碍物

### 雪块
- 外观：白色半透明覆盖在格子上的雪层
- 机制：占据格子；在其旁边做消除可打掉一层；常作为收集目标（"消除 N 个雪块"）
- 注意：雪块在格子上、动物在格子下——识别时注意层次不要和"冰块（包住动物）"搞混

### 冰块
- 外观：透明冰层**包裹住小动物**（动物在冰里）
- 机制：分 1~2 层；在旁边消除 1 次打掉一层；双层需两次；被冰包裹的动物不能移动/参与三消
- 注意：和雪块的区别——冰块包动物、雪块盖格子；播报建议用"冰里的狐狸"这类说法

### 锁链 / 藤蔓
- 外观：锁链或藤蔓缠住小动物
- 机制：被锁的动物**不能移动**但可参与消除；在旁边消除一次解开
- 注意：解开前不要把被锁动物当作可交换单位推荐走法

### 毒液
- 外观：紫色/绿色液态蔓延物
- 机制：**每走一步向周围格子蔓延**；在其旁边消除可清除；关卡目标有时要求"消除 N 个毒液"
- 注意：优先级最高——不及时处理会越铺越多；消除毒液可积攒星星瓶能量

### 蜂蜜
- 外观：琥珀色覆盖在动物/格子上
- 机制：需在旁边多次消除才能清除；常作为收集目标
- 注意：层数视觉上不明显，靠"还没消掉"的结果反推比靠外观数层更可靠

### 宝箱
- 外观：上锁的箱子，常出现在棋盘边缘/角落
- 机制：收集钥匙开启；箱下藏有关卡关键物（魔力鸟、移动地板等）
- 机制：钥匙通过消除下落收集，集齐后宝箱自动打开
- 注意：宝箱本身不可消除，不要推荐走法去"打宝箱"

### 翻转石门
- 外观：石质门板，周期性翻转开合
- 机制：门后格子平时被遮挡不可操作；翻转周期固定（有来源称错过一次等 3 步）[待核实：具体步数]
- 机制：要在门打开时尽快消除门后的目标
- 注意：时机型机关，播报可提示"石门还有 X 步翻转"[待核实]

### 传送带 / 传送门 / 滑道
- 外观：箭头传送带、漩涡传送门、轨道滑道
- 机制：动物从入口消失、从出口出现；金豆荚等收集物经滑道落入收集口
- 注意：棋盘拓扑不再是简单的"上掉下"，走法推荐算法必须考虑传送关系

### 银币
- 外观：银色硬币状障碍
- 机制：需旁边消除来清除；消除银币可触发墨鱼宝宝特效
- 注意：银币本身是障碍，同时是触发器——不要只当障碍处理

### 小叶堆 / 树叶
- 外观：堆叠的树叶覆盖物
- 机制：需多次消除清除；常伴随雪块出现
- 注意：[待核实：具体层数机制]

### 毛球（褐色毛球）
- 外观：褐色毛茸茸圆球
- 机制：**只能用特效消除**，普通三消无效
- 注意：不要推荐普通走法去打毛球，浪费步数

### 无敌毛球
- 外观：毛球的强化版，占据格子
- 机制：占据格子阻止动物进入；用特效可使其**暂时消失**一段时间，之后会回来
- 注意：消失是暂时的——策略是趁它消失的窗口期做事，不是"消灭"它

### 雪花
- 外观：雪花状小机关
- 机制：消除雪花可帮助消除周围障碍（助攻型）
- 注意：优先消除雪花常有奇效

### 云层
- 外观：白色云雾遮挡区域
- 机制：在旁边消除可驱散；遮挡视野和操作
- 注意：[待核实：具体驱散规则]

### 花团
- 外观：花束状
- 机制：消除魔法石可带动花团；部分关卡目标与花团有关
- 注意：[待核实：具体目标判定]

### 牢笼
- 外观：笼子关住小动物
- 机制：在旁边消除来解救被关动物；染色宝宝激活有助于开牢笼
- 注意：被关动物不计入"已收集"，必须先解救

### 鸡蛋壳
- 外观：蛋壳碎片状阻碍
- 机制：阻碍物，需消除
- 注意：[待核实：与"鸡蛋（孵化用）"的区别——疑似鸡蛋未孵化时的外壳状态]

### 冰块栏杆
- 外观：栏杆状冰块，分割棋盘区域
- 机制：阻挡动物通过，需消除
- 注意：[待核实]

## 四、收集目标物

### 小鸡（小黄鸡）
- 外观：黄色小鸡（同基础小动物）
- 机制：部分关卡目标"收集 N 只小鸡"；**靠鸡蛋孵化**：鸡蛋在旁边被消除后孵出小鸡；孵出的小鸡随机散落，可能自然形成消除
- 机制：同时孵化多个鸡蛋可提高连消概率
- 注意：小鸡是"孵出来"的不是"消出来"的——不要推荐三消小鸡来"收集"，要推荐去打鸡蛋旁边

### 鸡窝
- 外观：窝状，鸡蛋出现的位置
- 机制：孵化点；有来源称"消除鸡窝也容易产生特效"
- 注意：[待核实：鸡窝与鸡蛋的确切关系]

### 企鹅
- 外观：企鹅，常被雪块/锁链覆盖
- 机制：收集目标（"消除/解救 N 只企鹅"）；需先清除覆盖物
- 注意：企鹅常在角落，要用特效够

### 北极熊 / 雪怪 / 雪熊
- 外观：大型白色熊/怪兽，占据多个格子
- 机制：需多次消除其周围/身上冰块来解救；解救时有跳动动画+触发大炮等连锁
- 注意：它是"打"出来的不是"消"出来的——目标是破除覆盖物

### 精灵 / 精灵萌豆
- 外观：小精灵状
- 机制：收集目标
- 注意：[待核实：具体收集方式]

### 独眼仔
- 外观：单眼小怪
- 机制：消除独眼仔可产生更多特效（特效引擎）
- 注意：优先消除独眼仔攒特效

### 海豚
- 外观：海豚
- 机制：解救目标，藏在障碍后
- 注意：[待核实]

### 金豆荚
- 外观：金色豆荚，从上方下落
- 机制：落入**底部收集口**即收集；常经传送门/滑道到达收集口；气鼓鱼等障碍会挡住下落路线
- 注意：目标不是"消除"而是"送达"——走法要围绕打通下落通道

### 钥匙
- 外观：钥匙，随消除下落
- 机制：收集足够数量开宝箱；钥匙会持续下落直到集齐
- 注意：钥匙本身不是消除目标，是中间货币

### 宝石
- 外观：宝石
- 机制：收集目标（"收集 N 个宝石"）；消除魔法石/云层可收集
- 注意：[待核实：具体收集方式]

### 星星
- 外观：星星，出现在传送带等位置
- 机制：收集目标
- 注意：[待核实]

## 五、特殊生物 / 机关

### 水母宝宝
- 外观：小水母，半透明
- 机制：激活（旁边消除）后触发消除并带动连消；可由贝壳打爆获得
- 注意：水母宝宝够不到的死角（如底部海洋生物区）要留特效收尾

### 魔法炮 / 大炮
- 外观：炮筒状机关
- 机制：被触发后向固定方向发射，消除直线上雪块等障碍；可被水母/特效激发
- 注意：发射方向固定，识别时注意炮口朝向

### 贝壳
- 外观：贝壳
- 机制：打爆后放出水母宝宝
- 注意：贝壳是水母的来源，缺水母时优先打贝壳

### 气鼓鱼
- 外观：圆滚滚的鱼，受击会鼓胀
- 机制：消除后产生特效，消除周围障碍；常挡住金豆荚下落路线
- 注意：既是障碍又是特效来源——先利用后清除

### 魔法石
- 外观：发光石头
- 机制：激活（旁边消除）后带动大范围连消；可消除云层、带动花团、点亮染色宝宝
- 注意：魔法石是连锁发动机，优先激活

### 染色蛋
- 外观：彩色蛋，覆盖在格子上
- 机制：紧贴染色蛋做三消，蛋会**转化为消除动物同色的普通动物**；多蛋重叠区一次激活多个，制造连锁
- 注意：染色蛋是"变"不是"消"——转化后颜色取决于消除的动物颜色，推荐走法时要算颜色

### 染色宝宝
- 外观：染色蛋的升级/集满能量形态
- 机制：能量集满后与星星瓶交换→全屏消除；双染色宝宝交换→大面积消除；可被无敌毛球覆盖
- 注意：和"染色蛋"区分——蛋是转化，宝宝是能量型特效

### 星星瓶
- 外观：瓶子，内有星星能量，集满后发光
- 机制：通过消除毒液等积攒能量；集满后双星星瓶交换→大面积消除；与集满的染色宝宝交换→全屏消除
- 注意：能量未满的星星瓶不要急着用

### 精力瓶
- 外观：瓶子（与星星瓶不同色/形）[待核实：外观区分]
- 机制：双精力瓶互换→清屏消除
- 注意：[待核实：与星星瓶的确切区别]

### 章鱼
- 外观：章鱼
- 机制：**每步吐出毒液**；策略是攒到 4~5 个毒液后一次性消除，快速激活一对星星瓶
- 注意：章鱼是毒液源头——要么优先打章鱼，要么利用毒液攒能量，二选一

### 墨鱼宝宝
- 外观：小墨鱼
- 机制：消除银币可触发墨鱼宝宝特效，带走魔法石/魔法炮并下落银币
- 注意：银币→墨鱼→连锁，是一条固定连招

### 移动地板
- 外观：可移动的地板块，常藏在宝箱下
- 机制：改变棋盘可行走区域
- 注意：[待核实]
