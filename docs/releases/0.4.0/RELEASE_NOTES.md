# 听野 0.4.0 工程候选（未发布）

记录日期：2026-10-04。目标版本 `0.4.0 / versionCode 17`。本文件记录当前工程交付与验证边界，不是公开发布说明或安装指南。GitHub 最新公开体验版仍为 [0.3.8](https://github.com/ld0574/SenseField/releases/tag/v0.3.8)；0.4.0 尚未发布，本地工程交付存于 ignored `output/releases/0.4.0/`。

## 计划能力

- 选用式语音和画面助手：语音、画面理解和低频主动观察各自默认关闭、分别由用户启用。连续语音由用户选择，Android 10/API 29+ 使用本应用静音 `USAGE_GAME` 探测轨道确认有线/USB 耳机路由，BLE 路由识别从 API 31 起可用。用户须先确认游戏声已在耳机中；探测只证明本应用默认用途轨道的路由，不能证明游戏自选设备的轨道也走耳机。无耳机、未知/失败路由、`isClientSilenced()` 或其他录音会话出现时暂停上传，恢复前清空旧轮次。静音探测轨道不申请 audio focus、不设首选设备，但可能有额外 native 音频负载，仍待热/负载对照。开启后，端侧 VAD 片段经配置的 HTTPS/WSS 网关交给 CPU Python FunASR。显式画面问题通过网关交给 GLM-4.6V-Flash。此视觉模型的公开 API 输入/输出价格在 2026-10-03 标示为免费，但自托管网关、账号额度和速率限制仍适用。
- 消消乐合并时修复了声音设置被绕过、旧投影回调停止新会话、节流前不排空 ImageReader 和位图回收问题；两款游戏的采集互斥。
- 开心消消乐体验入口：可选游戏截图、校准棋盘区域和 6–9 行/列网格，按格颜色识别棋子并播报可形成三连的相邻交换；授权 MediaProjection 后可约每秒采样一次，在局面变化时播报。另有独立的 Jev 示例判定按钮，需要用户在判定自测页配置并启用渠道凭据。
- 王者荣耀路径保留端侧小地图检测和本地预警。实验性空间声像与距离触觉呈现选项默认关闭；这些开关不表示 HRTF、独立左右马达或玩家感知效果已验收。

## 当前验证记录

合并消消乐后的工作树通过 204 项 JVM、12 项 Android 14 arm64 本地 instrumentation、额外 2 项正式客户端真实 HTTPS/WSS 合成输入测试、native CTest 4/4 与 Python 530 项（1 项跳过）；arm64/x86_64 Debug 构建和 lint 通过。普通设备套件没有配置真实服务 fixture 时会跳过这两项传输测试。

CPU FunASR 使用固定 Paraformer streaming Apache-2.0 快照并核对了权重哈希。一次合成输入“请读出当前比分”的 smoke 在 2,510 ms 后得到 final；这是单个管线样本，不是 P95、语音质量结果或外部录音测得的用户端时延。外部录像中的 ASR final-recognition P95（目标 ≤1,000 ms）仍未测量，不能判定通过。

真实 GLM-4.6V-Flash 合成图读取正确，单次 API 请求 1,089 ms；Android 正式客户端经 TLS 校验的 HTTPS/WSS 完成真实 GLM、固定 CPU ASR 与 generation reset。Linux 隔离 HTTPS/WSS 合成测试通过，单次音频结束至 final 为 199 ms、GLM 网关请求为 1,804 ms，见[部署记录](../../development/assistant-gateway-test-deployment.md)。未测 Android→Linux 或实体麦克风，均非 P95。设备麦克风并发、SpeexDSP AEC 实效、外部实声 SLA、三组 15 分钟热/负载对照以及视障玩家体验均未验证。没有实体温升、游戏帧率、真实发声或玩家效用结论。

## 使用边界

- 语音和画面助手属于额外实验路径，不替代本机小地图预警，也不会自动提高历史符合度或改写 52.96% 历史评估结果。
- 消消乐棋盘结果依赖手动百分比标定、启发式颜色分类和样本棋盘逻辑。模板库和 Jev 示例路径不构成完整的特殊棋子规则识别；没有证明线上游戏局面的识别准确率。它不点击、交换棋子或代替玩家操作。
- 所有助手网络功能须由用户分别启用。画面可能包含聊天、通知或其他敏感内容；实际部署与 GLM 账户的日志、数据用途和保留条款仍须核对，不能承诺整条链路零留存。
- Release 状态、热表现、实际发声延迟与玩家验收保持未通过/待测；本记录不是发布授权。
