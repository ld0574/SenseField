## 使用变化

- 在「配置与调参」选择提醒音色，选中后直接试听。男声为 Fish「王者游戏解说男声」，女声为「游戏向导」，两者以选定的 0.9x 录音为 100% 基准；男声不添加逗号或试听停顿。音量与 80%～240% 语速仍可调整，重新开始辅助后应用新的设置。未设置音色时默认男声，已有女声选择保持；原晓晓映射女声、云希映射男声，已有手动语速与音量保留。完整说明保留原晓晓录音。
- 固定游戏提醒与完整说明使用内置语音。消消乐动态文字和助手回答继续使用所选手机离线中文引擎，设置名称为「动态文本语音引擎」。
- 试听可连续点击，新的试听替换旧播放。完整说明保留按段听、暂停、继续、旋转恢复和「跳过并开始」。
- 大字模式下音效、音色和动态引擎选择行随文字增高。
