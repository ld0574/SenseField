2026-10-13。拟定 0.4.7／versionCode 24，当前尚未实施版本递增、生成新 APK 或发布更新。当前可下载版本仍为 [0.4.6](../0.4.6/RELEASE_NOTES.md)。

本版计划改进两款游戏的提示稳定性、视觉感知与发热，详细范围、实施顺序和验收条件见 [0.4.7 版本规划](../../plans/0.4.7版本规划.md)：

工程验证继续使用已有日志和生产回放。日常反馈按正常使用收集，无需逐关重玩；独立准确率、实际听见、真人收益和受控温升各自记录证据。
