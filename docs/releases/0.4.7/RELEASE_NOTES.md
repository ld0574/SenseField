# 听野 0.4.7

Android `versionCode 24`，支持 Android 10 及以上的 arm64 设备。

## 本版更新

- **王者荣耀提醒**：根据已观察到的小地图目标和相对运动提供附近敌人、方向及接近提示，协调声音、语音与振动输出。
- **消消乐操作提示**：使用明亮的交换框、白色箭头与方位语音引导操作；有效提示保持显示，画面变化后重新判断。
- **棋盘与任务识别**：支持分离棋盘、毒液等元素的识别与任务读取，结合已确认的交换规则和目标收益排序。
- **语音与画面助手**：支持读图、游戏问答和决策分析；外放时可点击“说话”发起一次提问，耳机下可连续提问。
- **静音误识别修复**：识别结果只有句号、标点或空白时，不再触发助手回答，也不会打断正在等待的真实问题；单字回复和开放式提问仍可使用。
- **内置提示音**：提供游戏解说男声和游戏向导女声，可调语速、音量及提醒方式。

## 安装与开始

从 [GitHub Release](https://github.com/ld0574/SenseField/releases/tag/v0.4.7) 下载 APK，核对发布的 SHA-256 后安装。同包名、同签名可覆盖旧版并保留设置；同版本也可手动覆盖安装。

打开应用后选择游戏，按界面完成通知、录屏和悬浮窗授权，再切回游戏。王者荣耀使用横屏；消消乐可在需要时校准棋盘范围。结束时从应用或通知停止辅助。

## 使用条件

本地提醒依据当前可见画面，不推断未显示的敌人；消消乐对已确认的元素和规则给出建议，效果随关卡、设备与游戏版本变化。

助手默认关闭，需单独启用。语音识别在手机完成；开启画面功能后，授权截图和问题文本通过 HTTPS 发送到服务端模型。响应时间取决于网络和服务，即时游戏提醒由本地链路提供。动态中文播报需要手机中文 TTS。

服务端部署与 APK 分开更新，接入方式见 [助手部署](../../../deploy/assistant/README.md)。完整操作见 [安装指引](installation-guide.txt)，演示准备见 [路演指引](../../demo/录制说明.md)。
