# 听野 0.4.7 最终修订

0.4.7／code24，Android 10 及以上、arm64-v8a。按用户要求作为本版本最终交付，沿用此前证书，可覆盖安装同证书的 0.4.6 或旧 0.4.7，保留设置和本地记录。同 code 用户需手动下载安装，应用内版本检查不会提示本次修订。APK 为混淆、不可调试的 Release 构建；功能仍按体验版提供。

## 本次收尾

- 修复王者密集近敌提醒因优先级小幅上升而互相截断的问题。当前短句播完再接最新待播方位；提示音和振动按原设置即时输出，待播语音保留原 1.2 秒有效期。最高级预警仍可打断。独立新敌人继续按事件确认，未增加全局静默冷却。
- 合入 `feature/jev-l2-judgment` 的消消乐识别诊断补充：新元素样本记录模板及匹配距离，便于分析未识别原因。分支中的触觉语义表和噪声分档是独立逻辑，本版没有启用自动音量调整或替换现有振动。
- 取消 Demo 采录实验，移除脚本、测试页面、录制服务和编码器。正常“说话／说完”、耳机连续提问以及辅助所需的截屏识别继续保留。原有本地素材不进入发布包。

[收尾评估与 Goal](../../../validation/releases/FINALIZATION_ASSESSMENT_0_4_7_2026-10-15.md)记录了采纳和暂缓项；[最终发布核对](../../../validation/releases/GITHUB_RELEASE_0_4_7_FINAL_2026-10-15.md)绑定实际安装包、源码和验证范围。

## 消消乐

交换框加粗提亮，从棋盘中心沿白色箭头找到推荐位置，再按亮框内的方向交换或点击。语音使用“右上方可以消除”等棋盘方位和操作，能确认时补充动物名称，不再要求数行列。有效框持续显示；交换、消除、弹窗、停止辅助或画面失效后撤下。

新增毒液识别和目标读取，在旁边消除的确定收益进入任务排序，毒液格不可交换。修复上方孤立短行与下方主盘隔着空行时整盘无提示的问题。保留灰毛球、发光青蛙、末块雪块、魔力鸟组合与横向小黄鸡识别修复，未知规则和蔓延收益继续保留未知。

## 王者与游戏搭子

王者使用本地小地图预警。稳定、持续可见的相对接近可以触发入圈前提醒；突然出现或运动证据不足时按原近圈确认。声音、振动、方位和两字开关遵循已保存设置。接近提醒依据已观察到的运动，不能预知隐藏敌人或技能。

AI 助手默认关闭，开启后可读画面、回答游戏问题与分析选择。外放时展开小圆点，点“说话”开始一次提问，说完自动提交，也可点“说完”；五秒无声退出，单次最多十五秒。耳机下可连续提问。游戏开麦、系统静音、用户暂停、权限撤销或真正的麦克风竞争仍会暂停输入。原音只在本机临时处理，不保存音频文件。

每句完整、非空的识别文字按原话交给搭子理解，无固定问法白名单；暂停、复述等本地指令继续可用。新消息替换上一轮，空识别不打断。外放时请降低游戏音量，暂不对话时暂停连续语音。

回答直接播报正文，语速使用听野设置。提示音和振动可与回答并行；本地语音预警先播，随后续播未完成句段，原截图时效及问题归属不延长。新问题、暂停、撤权或原截图过期后不续播，诊断区分部分播放和完整完成。

升温降载只暂停自动观察与历史图片采样，主动提问、点击读画面、在途回答和复述继续可用。HUD 五秒、手动决策截图二十秒的时效保留。云端回答适合信息读取与分析选择，即时团战预警走本地链路。

本次最终收尾只需更新 APK，无需再次部署服务端。此前的中文提示词和输出兼容修订仍需单独部署；已经更新过的服务保持现状。当前使用 Qwen3.8-Flash、关闭思考，模型和 Key 只放在私有配置。中文提示词以“正在为低视力用户服务的游戏搭子”为身份，要求以可见信息为依据，未见敌人不等于安全，草丛或静止不足以建议“继续蹲点”。

下载 `sensefieldv0.4.7.apk`，核对同目录 `SHA256SUMS.txt` 后覆盖安装。选择游戏，按页面完成截屏、通知与悬浮窗授权。消消乐自动定位失败时可校准棋盘范围；王者自动定位小地图。
