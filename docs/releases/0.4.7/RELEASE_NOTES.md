# 听野 0.4.7 候选说明

0.4.7／code24，Android 10 及以上、arm64-v8a。本版先供候选验证，公开下载继续使用 0.4.6。

**部署提醒：本轮需要同步更新并重启 Python 服务端，核对现有代理等待时间。只安装 APK 无法启用新的手动截图预算和超时诊断。** 请按[已有服务更新步骤](../../../deploy/assistant/README.md#已有部署更新047-需要配套更新-python-服务端)更新源码，保留 K3、私有配置和运行时数据。前一版合成读图通过后，真实试用仍为零可用回答；本轮配套修复还需部署后复验。

本轮交付构建包含通用问答、手动截图时效与超时提示修订，安装包摘要以同目录 `validation/current-package/release-package.json` 为准。此前实局来自 `97957d1e…`；旧包回执继续绑定旧字节，不转移到新包。

## 体验变化

- 消消乐补横向特效小黄鸡的亮暗与箭头姿态，让已确认的特效进入合法交换与推荐。18 格同会话开发回放完整可用从公开 0.4.6 的 0 格提高到候选的 18 格，另 4 格为训练素材。
- 修复同步、迟到和重复语音回调、关闭语音后仍开始播放及生命周期恢复问题；诊断可关联提示请求与软件终态。
- 优化精确像素比较及当前帧棋盘几何计算，保持识别、门控与提示规则。
- 保留王者“两字方位提示”开关修复，以及消消乐灰毛球、发光青蛙、末块雪块与魔力鸟组合修复。
- 王者可在入圈前提醒稳定接近的可见敌人：连续三次新鲜敌我观测、相对运动一致且预计短时间内进入近圈才触发。声音、振动、方位和两字开关继续遵循原设置；同一次出现只提醒一次，缺少运动证据时保留原近圈确认。
- 画面理解明确区分模型服务访问拒绝与手机连接认证失败，提示检查服务端账户余额和接入配置，并暂停本次会话的自动读屏；手动读取成功后恢复自动观察。
- 云视觉以“正在为低视力用户服务的游戏搭子”为身份，帮助读取可见信息、回答游戏问题及分析选择，支持技能升级、区域观察等问题。默认只传当前截图，明确询问近期对比时才加入历史缩图；中文提示词独立放在可配置的服务端文件，依据实际画面和用户目标分析，不预设固定推荐。
- 后续源码修订让可靠的手动局内回答明确引用“约 N 秒前截图”，以原截图时间为起点最多保留 20 秒；主动观察与实时预警仍遵循原保护。未见敌方标记不能说明区域安全，重复回答不会重置时效。HTTP 504 明确报告读取超时。
- 手动读图单独给服务端 17 秒、手机 19 秒等待预算，代理示例为 21 秒；自动观察保留原预算。空判断与格式故障给出对应说明，不再误报为截图过期；中文提示词允许可靠的部分信息，服务端新增超时阶段诊断。

## 安装与反馈

沿用现有证书，覆盖同证书 0.4.6 时无需卸载；安装前核对 `SHA256SUMS.txt`。日常正常使用即可，出现无提示、错误交换、两字设置失效或明显发热时标记问题，停止辅助后私下导出诊断。详见[复测说明](复测说明.md)。
