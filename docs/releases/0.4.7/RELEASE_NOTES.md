# 听野 0.4.7 体验版

0.4.7／code24，Android 10 及以上、arm64-v8a，安装包约 24.59 MB（23.45 MiB）。本次提供混淆、不可调试的 Release 构建，可覆盖安装同证书的 0.4.6，保留原设置与本地记录。

## 本次更新

- 消消乐改善横向特效小黄鸡的亮暗与箭头姿态识别，让已确认的特效进入合法交换与推荐；优化像素比较与棋盘几何计算。保留灰毛球、发光青蛙、末块雪块及魔力鸟组合修复。
- 修复提示语音的同步、迟到和重复回调，以及关闭语音后的播放与生命周期恢复问题。
- 王者增加持续可见、稳定接近敌人的入圈前提醒。根据连续的新鲜敌我观测判断相对接近，声音、振动、方位与两字开关遵循原设置；突然出现或运动证据不足时使用原近圈确认。
- 游戏搭子支持读画面、回答游戏问题与分析选择，默认只传当前截图，明确询问近期对比时才加入历史缩图。手动读图与自动观察使用各自的等待预算，访问拒绝、超时、不确定与格式异常提供对应说明。
- 回答直接播报正文，去掉反复出现的“约 N 秒前截图显示”前缀；读画面先报告可靠可见的信息，有相关依据时再补建议。HUD 5 秒、手动决策截图 20 秒的过期保护继续保留，复述不会重置截图时间。
- 配套中文提示词以“正在为低视力用户服务的游戏搭子”为身份，补充本人及双方归属、战绩表和装备图标的判断边界。看不清装备不等于没有装备，未见敌人不等于安全；草丛或静止位置不足以建议“继续蹲点”。

## 服务端配套更新

当前服务使用 Qwen3.8-Flash，关闭思考。10 月 15 日的提示词修订需由部署者单独替换有效提示词文件并重启服务，安装 APK 不会更新服务器。交付包中的 `服务端更新/` 含提示词 ZIP、校验文件及更新说明，保留现有模型、私有配置与运行数据即可；提示词包不含 Key、私有配置或用户素材。

AI 助手默认关闭，可按需开启。云端画面理解适合读取信息和分析选择，即时团战提醒使用本地预警；接近提醒依据已观察到的运动，无法预知隐藏敌人或技能。

## 已验证范围

Android Debug 与 Release 各 633 项 JVM 单测、Release lint、相关 Python 358 项回归通过。APK 身份、签名与语音资产检查通过，已覆盖安装测试手机，安装后回读 SHA-256 与交付包一致。

更新前一次约 9 分 39 秒的王者试用中，14 次云请求包含 12 次正常回答、1 次不确定和 1 次因新问题取消，未观察到超时；正常回答的供应商耗时中位数约 2.07 秒。该记录来自前一手机修订，体现当时服务通路，不能代表本包全部回答正确或新提示词已生效。

本版按体验版提供。最终包的独立准确率、策略收益、完整实局连续录制、受控温升及整体成本稳定性仍待验，新提示词也需部署后复核。历史失败和旧包验证结果保留原制品绑定。

## 安装与反馈

下载 `sensefieldv0.4.7.apk`，安装前核对同目录 `SHA256SUMS.txt`；同证书覆盖安装无需卸载。选择游戏，按页面完成录屏、通知与悬浮窗授权，再开始辅助。消消乐自动定位失败时可校准棋盘范围，王者使用自动小地图识别。

正常使用即可。遇到无提示、错误交换、语音中断或明显发热，可在通知中标记问题，停止辅助后私下导出诊断；诊断不会自动上传。复测要点见同包 `复测说明.md`。
