# 听野 0.4.7 候选说明

0.4.7／code24，Android 10 及以上、arm64-v8a。本版先供候选验证，公开下载继续使用 0.4.6。

**部署提醒：本轮需要同步更新并重启 Python 服务端。只安装 APK 无法启用新的中文搭子提示词和选人／出装服务逻辑。** 请按[已有服务更新步骤](../../../deploy/assistant/README.md#已有部署更新047-需要配套更新-python-服务端)更新源码，保留私有配置和运行时数据；切换中转后执行真实合成读图验收。生产服务器尚未由本次本地交付更新。

## 体验变化

- 消消乐补横向特效小黄鸡的亮暗与箭头姿态，让已确认的特效进入合法交换与推荐。18 格同会话开发回放完整可用从公开 0.4.6 的 0 格提高到候选的 18 格，另 4 格为训练素材。
- 修复同步、迟到和重复语音回调、关闭语音后仍开始播放及生命周期恢复问题；诊断可关联提示请求与软件终态。
- 优化精确像素比较及当前帧棋盘几何计算，保持识别、门控与提示规则。
- 保留王者“两字方位提示”开关修复，以及消消乐灰毛球、发光青蛙、末块雪块与魔力鸟组合修复。
- 王者可在入圈前提醒稳定接近的可见敌人：连续三次新鲜敌我观测、相对运动一致且预计短时间内进入近圈才触发。声音、振动、方位和两字开关继续遵循原设置；同一次出现只提醒一次，缺少运动证据时保留原近圈确认。
- 画面理解明确区分模型服务访问拒绝与手机连接认证失败，提示检查服务端账户余额和接入配置，并暂停本次会话的自动读屏；手动读取成功后恢复自动观察。
- 云视觉明确以“正在为低视力用户服务的游戏搭子”为身份，聚焦选人和后续出装。默认只传当前截图，明确询问近期对比时才加入历史缩图；两个决策场景支持较长等待，并在页面持续明显变化后撤销旧建议。中文提示词独立放在服务端文件，可配置调整；依据实际画面和用户问题推荐，不预设固定英雄或出装。新中转实测优先选 Kimi-K3，生产服务器切换和公网恢复仍待实测确认。

## 验证范围

工程过程见[版本规划](../../plans/0.4.7版本规划.md)和[视觉修复报告](../../../validation/match3/VISUAL_CONVERGENCE_0_4_7_2026-10-14.md)。各批历史性能结果保持原制品绑定；最终候选以交付目录 `validation/current-package/` 中源码、APK、套件、回放、处理成本及持续运行回执为准。

[与实际公开 0.4.6 的原包对照](../../../validation/performance/PUBLIC_APK_COMPARISON_0_4_7_2026-10-14.md)已完成开发质量及两款游戏各三组成对保留生产阶段成本，原历史标签错误计数未增加。该报告绑定先前候选 `a0c83659…`；本轮提示与服务错误修订另见[Hero 反馈复盘](../../../validation/honor/HERO_FEEDBACK_2026-10-14.md)，不把旧包的完整工程结果自动转移给新包。完整实局提示与物理验收保持以下范围。

独立准确率、实际提示采纳与通关收益、最终包真机发声及受控 3×15 分钟温升仍待验。开发素材和模拟器处理结果用于工程修复与回归。

本轮最终包功能回归通过；王者软件成本三组有一组P95超过10%门槛，同包A/A也出现明显波动，成本总体不能记为通过，需在稳定空闲条件下复验。先前包的900秒持续运行不转移到新候选。

## 安装与反馈

沿用现有证书，覆盖同证书 0.4.6 时无需卸载；安装前核对 `SHA256SUMS.txt`。日常正常使用即可，出现无提示、错误交换、两字设置失效或明显发热时标记问题，停止辅助后私下导出诊断。详见[复测说明](复测说明.md)。

本地候选尚未公开发布；候选 APK、清单与校验文件同目录生成。Gitee 与公网清单由用户同步，公开后再更新 README 下载入口。
