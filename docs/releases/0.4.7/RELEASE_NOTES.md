## 变化与实际回放

已确认的任务完成和直接收益继续优先。收益相同且接触相同数量饼干托盘时，比较这一步确定清掉多少个紧贴托盘的动物，再比较距离和生成新特效的机会。一个2×2托盘仍只算一次接触，周边消除数不当作饼干数量或保证伤害；不会给所有魔力鸟走法统一加分。

原0.4.6冻结包在队友后段保存图中漏认魔力鸟和最后托盘，首选无关四连。修订回放将第3行第5列魔力鸟与左侧第3行第4列红狐狸交换排首位：红色消除在剩余托盘旁有2处确定接触，其他相邻可交换颜色为1处或0处。用户附图那帧已经没有魔力鸟，修订后首选第8行第4列与第9行第4列交换，在饼干旁形成消除。这些是同源开发回放，不能宣称独立准确率或实际通关收益。

补充外观使用现有飞轮审阅和编译：1个魔力鸟描述符、2个饼干托盘描述符。原规则、阈值和图库预算保持；饼干机制及HUD事件模式仍未知，花团等机制也继续弃权。魔力鸟和未核实特效的组合没有开放。
