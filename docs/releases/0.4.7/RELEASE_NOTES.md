# 听野 0.4.7 体验版

0.4.7／code24，Android 10 及以上、arm64-v8a。本次按用户要求保留版本号并修订安装包，提供混淆、不可调试的 Release 构建，可覆盖安装同证书的 0.4.6 或旧 0.4.7，保留原设置与本地记录。同版本用户请手动下载安装，应用内版本检查不会提示同 code 更新。

## 本次更新

- 外放时可在小圆点面板点“说话”提问，说完自动提交，也可点“说完”结束；五秒未检测到说话退出，单次最长十五秒。耳机下仍可连续提问。Demo 录屏的系统输出回录不会再被误判成麦克风占用；系统静音、游戏开麦、真正的麦克风竞争或未知录音源仍暂停输入。明确区分输入暂停、语音资源准备和识别结果，新增语音窗口与本地 ASR 就绪诊断。
- 修复上方孤立短行、下方收窄主盘之间隔着空行时自动定位失败、整盘没有提示的问题。两个区域按当前格距与边界核对完整网格，空洞不能交换；特效遮挡主盘时仍等待稳定画面，不按关卡号固定范围。
- 消消乐新增毒液识别，修正毒液目标被读成饼干的问题；在旁边消除的确定收益进入任务排序，优先完成剩余毒液。毒液本身不能交换，尚未确认的蔓延方向与数量不作为确定收益。
- 消消乐交换框加粗为亮黄边框与深色描边，新增从棋盘中心指向推荐位置的白色引导箭头，并保留两颗棋子的交换方向。语音改说“右上方可以消除，青蛙和红狐狸上下交换”等方位与操作，不再播报第几行第几列；点击特效单独说“点击”，方位以整个棋盘为准。
- 有效高亮持续留在原位，不按固定秒数消失；交换、消除、弹窗、停止辅助或画面失效时撤下。增加连续 30 秒可见与边缘格检查，撤框日志同时记录原因和已显示时长，方便定位实局中的提前消失。
- 修复游戏搭子回答被提醒直接丢弃：提示音和振动可与回答并行；需要播报本地语音预警时先让路，预警结束后从未完成的句段继续。已播完的句段不重复，原截图时效与问题归属不延长；新问题、暂停或撤权仍取消旧回答。语速继续使用听野保存的设置。
- 修复长回答后段没有播放却被记为完成的问题，区分完整完成、部分播放后过期和长度预算中断。
- 配套服务端兼容无害的额外输出字段，不再仅因超过两句或一百字就将可读答案整段作废；保留手机四百 UTF-16 单位的传输上限，不强截否定、条件或不确定性。中文提示词进一步要求短结论在前、必要依据在后；这部分需更新 Python 与提示词并重启服务。
- 移除连续语音的问法白名单：识别完成的每句非空文字都作为消息，保留原话交给游戏搭子理解，陈述句或少见说法也可参与对话。暂停、复述和麦克风检查等本地指令继续可用；空识别结果不打断等待中的回答。完整新消息会替换上一轮，请在暂时不想对话时暂停连续语音。
- 保留升温后主动问答修复：高温降载只暂停后台自动观察与历史图片采样，主动语音提问、点击读画面、在途回答及复述继续可用。温度变化不再重置手动问答或丢弃正在等待的语音结果；本地识别继续降载，截图过期、用户暂停与权限检查保持生效。
- 消消乐改善横向特效小黄鸡的亮暗与箭头姿态识别，让已确认的特效进入合法交换与推荐；优化像素比较与棋盘几何计算。保留灰毛球、发光青蛙、末块雪块及魔力鸟组合修复。
- 修复提示语音的同步、迟到和重复回调，以及关闭语音后的播放与生命周期恢复问题。
- 王者增加持续可见、稳定接近敌人的入圈前提醒。根据连续的新鲜敌我观测判断相对接近，声音、振动、方位与两字开关遵循原设置；突然出现或运动证据不足时使用原近圈确认。
- 游戏搭子支持读画面、回答游戏问题与分析选择，默认只传当前截图，明确询问近期对比时才加入历史缩图。手动读图与自动观察使用各自的等待预算，访问拒绝、超时、不确定与格式异常提供对应说明。
- 回答直接播报正文，去掉反复出现的“约 N 秒前截图显示”前缀；读画面先报告可靠可见的信息，有相关依据时再补建议。HUD 5 秒、手动决策截图 20 秒的过期保护继续保留，复述不会重置截图时间。
- 配套中文提示词以“正在为低视力用户服务的游戏搭子”为身份，补充本人及双方归属、战绩表和装备图标的判断边界。看不清装备不等于没有装备，未见敌人不等于安全；草丛或静止位置不足以建议“继续蹲点”。

## 服务端配套更新

当前服务使用 Qwen3.8-Flash，关闭思考。本轮输出校验修复需部署者替换 `app.py`、`validation.py` 与有效的 `vision_prompt.txt` 并重启服务，安装 APK 不会更新服务器。交付目录 `服务端更新/` 提供这三个文件、校验文件及更新说明；保留现有模型、私有配置、代理与运行数据。更新文件不含 Key、私有配置或用户素材。

本次外放语音入口、消消乐棋盘定位、毒液与高亮修订仅需更新 APK；此前已经完成上述服务端更新的用户无需重复部署。

AI 助手默认关闭，可按需开启。云端画面理解适合读取信息和分析选择，即时团战提醒使用本地预警；接近提醒依据已观察到的运动，无法预知隐藏敌人或技能。

## 安装与反馈

下载 `sensefieldv0.4.7.apk`，安装前核对同目录 `SHA256SUMS.txt`；同证书覆盖安装无需卸载。选择游戏，按页面完成录屏、通知与悬浮窗授权，再开始辅助。消消乐自动定位失败时可校准棋盘范围，王者使用自动小地图识别。

正常使用即可。遇到无提示、错误交换、语音中断或明显发热，可在通知中标记问题，停止辅助后私下导出诊断；诊断不会自动上传。复测要点见同包 `复测说明.md`。

## 安装包校验

文件 `sensefieldv0.4.7.apk` 的大小与 SHA-256 以交付目录的 `SHA256SUMS.txt` 和 `validation/current-package/release-package.json` 为准。先前各修订的历史验证继续保留原摘要绑定。签名沿用此前公开包的 Android debug 证书，用于兼容覆盖安装；APK 为混淆、不可调试的 Release 构建。
