# 听野 0.4.7 验收准备（规划）

当前尚无新 0.4.7 APK；此页用于准备冻结后的验证。可下载版本仍为 [0.4.6](../0.4.6/RELEASE_NOTES.md)。完整范围见 [版本规划](../../plans/0.4.7版本规划.md)，旧同名候选见 [历史归档](../../../validation/releases/ANDROID_WITHDRAWN_0_4_7_2026-10-12.md)。

## 工程端先完成

1. 使用已有日志和冻结画面，复核长时间无提示、语音取消、设置开关及视觉难样例；运行生产回放与生命周期反例。
2. 完成识别、规则、事件时序、软件成本、构建及包完整性检查，冻结唯一候选 APK；记录源码、包和输入摘要。
3. 安装冻结 APK 并回读 SHA，自动检查覆盖安装、设置保持、启动／停止、过期提示撤销、故障恢复和固定输入持续运行。
4. 两款游戏分别按同机、同条件、匹配起始温度进行前台成本及各模式 3×15 分钟温升对照；提前停止或缺条件时列明待验。工程端负责监控与回收日志。

## 日常体验反馈

用户正常开始辅助、游戏并停止辅助即可，无需重玩指定关卡。遇到问题时可使用通知中的“标记问题”，结束后在“测试记录与反馈”导出对应记录。手机只保留最近三局，分享前先导出需要保留的记录。

- 消消乐：留意有发光／特效、覆盖或移动元素时是否能给出可靠提示，高亮与语音位置是否一致，最后目标附近建议是否合理。
- 王者：留意近区出现／再出现时的提醒，两字开关是否按自己的选择执行，前后台切换后提示是否恢复。
- 两款游戏：留意提示实际听见与完成情况，以及发热体感；明显烫手或不适时结束。

反馈带上手机型号、Android 版本、游戏场景、语音引擎／音频路线和现象即可。诊断仅本地保存，由用户导出和分享；可能含昵称、聊天或通知，分享前确认愿意提供。

## 记录范围

软件回调与实际听见分别登记；日常短局反馈与受控温升分别记录。独立识别准确率、真人收益及严格最终验收按原协议采集。验收结果绑定最终 APK 摘要，旧 0.4.6 或撤回候选的通过结果保持原制品绑定。
