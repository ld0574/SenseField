# 0.4.7 候选复测

覆盖安装后确认原游戏设置仍在。消消乐优先留意横向特效动物、最后目标及稳定盘面是否有及时、位置正确的提示；王者确认关闭两字提醒时密集场景也使用完整措辞。

王者留意敌人持续接近时，提醒是否给了反应时间。同一目标持续可见时不会在入圈后再重复；突然出现或运动证据不足时仍按近圈确认。反馈可区分“提醒已经发出但来不及反应”与“完全没提醒”，按正常游戏体验即可。画面理解需先由负责人恢复提供商余额或更换中转站并通过合成读图验收；随后手机手动读取一次，正常返回后自动观察恢复。

按日常玩法使用即可。遇到无提示、提示不符或语音中断，在通知中标记问题，停止辅助后私下导出诊断。可补一句“是否听到、画面上应选什么、是否正在充电”；不需要逐关重玩或手工标注。

画面理解优先在选人和装备页面使用，也可明确问“接下来怎么出装”。听野以“正在为低视力用户服务的游戏搭子”为身份，先说一个选择和依据；等待过程中如果已换页面，旧建议应撤销。需要比较前后变化时再明确说明，默认只传当前截图。云端响应可能需要5～10秒，即时团战提醒使用本地链路。新提示词以中文文件维护，可在服务器配置中调整；实际公网切换和最终手机体验分别验收。

受控温升与外部实声测量由工程端按条件另行组织。感觉明显烫手或不适时停止使用；单次体感与后台固定输入运行不记为温升验收通过。
