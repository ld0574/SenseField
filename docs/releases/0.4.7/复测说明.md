# 听野 0.4.7 队友复测

直接覆盖安装0.4.7，正常玩一两局即可，不必重复指定关卡或额外录屏。

1. 确认听野版本0.4.7。在开心消消乐的「测试记录与反馈」确认「保存游戏画面」开启，选择平时使用的语音引擎，开始辅助并完成录屏授权。
2. 正常游戏；遇到魔力鸟时留意提示选的颜色是否有助于剩余任务。留意饼干周边推荐、交换框位置、语音和发热情况。行列从整个棋盘左上角开始编号。
3. 遇到不合理推荐、整局无提示、长期无语音或框偏位，可在听野通知点「标记问题」，记下关卡和现象即可。明显烫手时结束测试。
4. 每局结束后停止辅助，回到「测试记录与反馈」，选择对应记录，补充问题说明，再导出并私下分享ZIP给开发者。手机只保留最近3局，先导出再继续多局。

反馈带上手机型号、Android版本、关卡、语音引擎，以及提示是否照顾剩余目标、是否听到语音、发热体感即可。诊断可能含昵称、聊天或通知，分享前请确认愿意提供。

本次补充魔力鸟和托盘识别及排序；饼干层数和实际消除收益仍未知，不保证一次清完。连消或棋盘变化时可能取消旧提示；未核实的魔力鸟与特效组合继续弃权。
