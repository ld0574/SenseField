# 0.4.7 体验版复测要点

覆盖安装后确认原设置仍在，按日常玩法使用即可，无需逐关重玩或手工标注。

本次是 0.4.7／code24 同版本修订，已安装旧 0.4.7 的用户需手动下载覆盖安装，应用内版本检查不会提示同 code 更新。播报修复随 APK 生效；输出校验兼容与新提示词需同步更新 Python 服务。

- 消消乐：交换框现在更粗、更亮，从棋盘中心沿白色箭头找到推荐位置。语音只说棋盘方位、动物名称与左右交换／上下交换／点击，不再要求数行列。稳定盘面上的有效框应持续显示，方便慢慢找，不因语音结束就消失；交换、消除、弹窗或停止辅助后应撤下旧框。正常使用即可，无需为此逐关重玩。
- 毒液：应读取毒液目标，并优先推荐能清理邻近毒液、完成剩余目标的合法交换；毒液格本身不能交换。工程端已经用本次日志与截图自动回放，无需重玩第 121 关。数量看不清时明确弃权，不猜蔓延方向或后续数量；本次适配只需更新 APK。
- 分离棋盘：修复第 123 关上方孤立三格、下方收窄主盘导致整盘无提示的问题，保留两行空洞；特效遮挡主盘时暂不推荐，稳定后恢复。已用这次日志的稳定图、遮挡图与模拟器截屏自动核验，无需专门重玩该关。
- 王者：关闭两字提醒后，密集场景也应使用完整措辞；敌人持续接近时留意是否提前提醒、同一目标是否重复提醒。突然出现或运动证据不足时仍按近圈确认。
- 游戏搭子：先开启 AI 助手，再按需读画面或提问。回答应直接进入正文，不再反复播报截图年龄；能确认的信息应优先报告。看不清装备不能说成没有装备，战绩表首行不能直接当成本人，草丛、静止位置或未见敌人不能单独支持“继续蹲点”。
- 连续语音：每句完整、非空的识别文字都应作为消息进入对话，不需要问号、固定口令或指定主题，陈述句也交给搭子理解；暂停、复述等本地指令仍直接处理。新消息替换上一轮，空识别不打断待答问题。不想对话时暂停连续语音。控制器回归不代表真实麦克风识别率或模型答案正确性。
- 播报：听野语速设置继续生效。纯提示音和振动不应取消回答；需要说话的本地预警先播，随后续播原回答未完成的句段。新问题、暂停、撤权或原截图过期后不续播；不得将后段丢弃记为完整完成。这些时序可用合成事件验证，不要求再打一整局。
- 温控：工程端已使用软件高温状态检查主动语音提问、读画面、在途回答和复述继续可用，自动观察与历史采样暂停；日常使用自然遇到升温时留意即可，不要为复测专门加热手机。截图过期、用户暂停和麦克风安全限制仍生效。

当前服务使用 Qwen3.8-Flash，关闭思考。配套的 app.py、validation.py 与有效提示词需要部署者单独更新并重启服务，步骤见交付目录 `服务端更新/服务端更新说明.md`；没有更新时不能将输出兼容或回答风格归因于本轮服务端修订。可优先用已有截图复核，不要求重新打一整局。

画面理解支持技能升级、区域观察、选人、出装及其他游戏问题，不预设固定答案。云端耗时随服务情况变化，单次快答不保证每次都快；实时团战提醒使用本地链路。截图中未见敌人不等于区域安全。

HUD 5 秒、可靠手动决策截图 20 秒过期保护保留，复述使用原采集时间。手动读图的服务端、手机等待上限分别为 17 秒、19 秒，代理示例为 21 秒；自动观察使用原预算。超时应报告“画面读取超时”，模型不确定或格式异常应给出对应说明。

遇到无提示、提示不符或语音中断，可在通知中标记问题，停止辅助后私下导出诊断；可补一句是否听到、是否正在充电，不必回忆全部问答。感觉明显烫手或不适时停止使用。

本次工程回归与 APK 核对范围以 validation/current-package/ 为准；未安装到手机时不记为真机通过。受控温升、成本稳定性、独立准确率和完整实局录制由工程端按条件另行验证，日常体感或软件语音回调不能替代这些验收。
