# 0.4.7 体验版复测要点

覆盖安装后确认原设置仍在，按日常玩法使用即可，无需逐关重玩或手工标注。

本次是 0.4.7／code24 同版本热修订，已安装旧 0.4.7 的用户需手动下载覆盖安装，应用内版本检查不会提示同 code 更新。只需更新 APK，服务器无需再次更新。

- 消消乐：留意横向特效动物、最后目标与稳定盘面是否有及时、位置正确的提示，提示语音是否完整。
- 王者：关闭两字提醒后，密集场景也应使用完整措辞；敌人持续接近时留意是否提前提醒、同一目标是否重复提醒。突然出现或运动证据不足时仍按近圈确认。
- 游戏搭子：先开启 AI 助手，再按需读画面或提问。回答应直接进入正文，不再反复播报截图年龄；能确认的信息应优先报告。看不清装备不能说成没有装备，战绩表首行不能直接当成本人，草丛、静止位置或未见敌人不能单独支持“继续蹲点”。
- 温控：工程端已使用软件高温状态检查主动语音提问、读画面、在途回答和复述继续可用，自动观察与历史采样暂停；日常使用自然遇到升温时留意即可，不要为复测专门加热手机。截图过期、用户暂停和麦克风安全限制仍生效。

当前服务使用 Qwen3.8-Flash，关闭思考。配套提示词需要部署者单独更新并重启服务，步骤见交付包 `服务端更新/服务端更新说明.md`；没有更新时不能将回答归因于新提示词。可优先用已有截图复核，不要求重新打一整局。

画面理解支持技能升级、区域观察、选人、出装及其他游戏问题，不预设固定答案。云端耗时随服务情况变化，单次快答不保证每次都快；实时团战提醒使用本地链路。截图中未见敌人不等于区域安全。

HUD 5 秒、可靠手动决策截图 20 秒过期保护保留，复述使用原采集时间。手动读图的服务端、手机等待上限分别为 17 秒、19 秒，代理示例为 21 秒；自动观察使用原预算。超时应报告“画面读取超时”，模型不确定或格式异常应给出对应说明。

遇到无提示、提示不符或语音中断，可在通知中标记问题，停止辅助后私下导出诊断；可补一句是否听到、是否正在充电，不必回忆全部问答。感觉明显烫手或不适时停止使用。
