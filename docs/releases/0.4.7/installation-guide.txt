听野 0.4.7 体验版使用说明

安装要求：Android 10 及以上、arm64-v8a。版本 0.4.7，versionCode 24，包名 com.openkhub.sensefield。沿用现有证书，可覆盖同证书 0.4.6 或旧 0.4.7，无需卸载，保留游戏设置与本地记录。安装前核对同目录 SHA256SUMS.txt。同版本用户请手动下载并覆盖安装，应用内版本检查不会提示同 code 更新。

使用：选择游戏，按页面完成录屏、通知与悬浮窗授权，然后开始辅助。消消乐自动定位失败时可校准棋盘范围；王者使用自动小地图识别，声音、振动、方位与两字开关继续遵循保存的设置。

消消乐交换框已加粗提亮，从棋盘中心沿白色箭头可找到推荐位置，再按亮黄框内的方向交换或点击。语音只报左上方、右侧、中间等方位与操作，不再播报第几行第几列；能确认时补充动物名称。有效提示会一直显示，方便慢慢找，不按固定秒数消失；交换、消除、弹窗、停止辅助或画面失效时撤下。显示问题的诊断现包含撤下原因与已显示时长。
新增毒液识别与毒液任务读取，修正误认饼干；在旁边消除的确定收益进入推荐，能清完剩余毒液的交换优先。毒液不能作为交换端点，尚未确认的蔓延数量与方向保留未知。
修复上方孤立短行与下方主盘之间隔着空行时整盘无提示的问题，保持完整坐标和不可交换的空洞；特效遮挡主盘时仍等待稳定画面。已用本次故障截图自动回放，无需逐关重玩。
本次棋盘定位、毒液与高亮改动只需更新 APK，已完成此前服务端修复的用户无需重复部署。

本轮改善消消乐特效识别与提示回调，优化棋盘处理；保留灰毛球、发光青蛙、末块雪块和魔力鸟组合修复。王者新增稳定接近敌人的入圈前提醒，依据已观察到的相对运动，不能预知隐藏敌人或技能。

AI 助手默认关闭。开启后可读画面、回答游戏问题与分析选择；默认只传当前截图，需要比较前后变化时明确说明。回答直接播报正文，不再反复加“约几秒前截图显示”；HUD 5 秒、手动决策截图 20 秒过期保护保留。云端回答时间随服务情况变化，即时团战提醒使用本地预警。

外放时可点助手面板的“说话”进行一次语音提问，说完自动提交，也可点“说完”结束。五秒未检测到说话会退出，单次最长十五秒；窗口外不进入语音识别。耳机下仍可连续提问。通过 scrcpy 等工具录制 Demo 时，系统输出回录不会再阻断这个单次语音入口；真正占用麦克风的应用仍会触发暂停。请降低游戏音量，避免游戏人声混入；系统静音、用户暂停或撤回麦克风权限时，两种方式都会暂停。本次语音入口改动只需更新 APK，无需重新部署服务端。

本次修订：提示音和振动不再取消助手回答；本地语音预警优先，预警结束后从未完成的句段继续，原时效和问题归属不延长。尾段过期或被长度预算截停时，诊断会区分部分播放与完整完成。语速继续使用听野保存的设置。

升温时仍只暂停后台自动观察和历史图片采样，主动语音提问、点击读画面、在途回答和复述继续可用；本地识别继续降载，用户暂停、权限、过期和服务限流检查保留。

本次移除连续语音的问法白名单。识别完成的每句非空文字均作为消息，原话交给游戏搭子理解，陈述句和少见说法也可参与对话；暂停、复述、麦克风检查等本地指令继续可用。完整新消息会替换上一轮等待中的回答，空识别结果不会打断。背景人声也可能被识别并发送；暂时不想对话时，请暂停连续语音。

服务端配套：当前服务使用 Qwen3.8-Flash，关闭思考。本轮兼容额外输出字段，不再仅因超过两句或一百字就将可读答案整段作废，必要条件与否定不强行截断；提示词要求短结论在前。部署者需按“服务端更新/服务端更新说明.md”覆盖 app.py、validation.py 和有效提示词，再用原管理器重启。仅安装 APK 不会更新服务器；保留现有模型、Key、私有配置、代理和运行数据。更新文件不含 Key 或用户素材。

工程检查：本轮测试与最终包核对结果见 validation/current-package/，此前包的实局与工程结果保留原摘要绑定。高温模式用软件状态模拟，未实际加热手机。

本版供体验。独立准确率、策略收益、最终包受控温升、整体成本稳定性及完整实局连续录制仍待验，提示词修订需部署后复核。正常使用即可，遇到异常可在通知中标记，停止辅助后私下导出诊断；诊断不会自动上传。
