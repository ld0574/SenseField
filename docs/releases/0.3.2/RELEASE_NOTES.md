# 听野 0.3.2 内部候选

2026-10-02 交付；以下保留交付时的说明与验证边界。

APK 为 Android Debug 签名，仅 arm64-v8a，Android 10（API 29）及以上。安装升级必须与现有包签名兼容；本轮没有发布 GitHub Release。

1. 启动后选择王者荣耀，点“开始”，先听提醒释义，再确认本次截屏授权。
2. 标准模式同时使用方位语音、方向双短音与双震动；先在设置测试语音和震动。应用自动选择识别配置。
3. 完成一局后停止辅助，进入“设置 → 测试记录与反馈”，导出或保存该局诊断包；无需另开系统录屏。
4. 若应用异常退出，重新打开后该局会显示“记录中断（已恢复）”，仍可导出；准确结束时刻与总时长可能未知。
5. 反馈没报／迟报／误报时附上对局时刻、耳机类型、听感与发热感受。画面默认本地采样，可关闭；分享前确认包内画面可提供给队友。

已完成软件回归与模拟器诊断恢复验证。实体手机误报／漏报、实际发声延迟、震动感知和发热尚未通过独立门禁；患者仅做有陪同的实验试用。
