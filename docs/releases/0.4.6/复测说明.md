# 听野 0.4.6 队友复测

本次是开心消消乐辅助的体验测试。正常玩一两局即可，不需要逐关重玩、额外录屏或手工标注。

1. 下载 `sensefieldv0.4.6.apk`，直接覆盖安装旧版听野，确认版本为 0.4.6。适用 Android 10 及以上 arm64 手机；安装失败时保留系统提示并反馈，不必先卸载旧版。
2. 在听野的「开心消消乐 → 测试记录与反馈」确认「保存游戏画面」开启；选择平时使用的语音引擎，开始辅助并完成录屏授权，再正常进入游戏。
3. 留意棋盘稳定时是否有提示，语音能否听清，以及高亮的位置和行列编号是否对应。编号从整盘左上角开始。推荐仍需自己判断，正常操作即可。
4. 遇到整局无提示、长期无语音、框偏位或不合理推荐，可在听野通知中点「标记问题」。记下关卡和现象即可；留意发热是否影响正常操作，明显烫手时结束测试。
5. 每局结束后停止辅助，回到「测试记录与反馈」，选择对应记录，补充关卡及问题说明，然后「导出并分享诊断包」给开发者。先导出再继续多局，手机仅保留最近 3 局。

反馈尽量带上手机型号／Android 版本、关卡、使用的语音引擎、能否听到提示、高亮是否准确、发热体感及对应 ZIP。没有遇到问题也可以写“提示正常／语音正常／发热可接受”。

记录默认仅保存在手机，不自动上传；分享前确认愿意提供其中可能出现的昵称、聊天或通知。花团等未知机制可能没有相关收益提示，连消或局面变化时可能取消旧提示，不保证通关。最新包的长时稳定与受控温升尚待测试。
