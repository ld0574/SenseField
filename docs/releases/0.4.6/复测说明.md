# 听野0.4.6队友复测

覆盖安装本次0.4.6并正常使用即可，版本名保持0.4.6，请用文末SHA确认修订。无需逐关重玩或手工标注。

1. 在开心消消乐「测试记录与反馈」确认「保存游戏画面」开启，选择平时使用的语音引擎，开始辅助并完成录屏授权。
2. 遇到灰毛球时留意是否识别任务、推荐能清理毛球的交换；也留意右侧最后一块雪块、魔力鸟与直线特效动物组合，以及发光青蛙、最后饼干和交换语音。
3. 若建议不合理、整局无提示或框偏位，通知中点「标记问题」，写关卡和现象即可。结束后停止辅助，私下导出对应记录；手机只留最近3局，请先导出再继续多局。

反馈附手机型号、Android版本、关卡和语音引擎即可。灰毛球底层颜色不明、移动落点和组合的额外命中仍会保留不确定；不保证一步通关，局面变化会撤销旧提示。

王者正常使用时可留意“两字方位提示”的选择：关闭应播“左上有敌人”等完整语句，开启应播“左上”等两字方位，密集场景也遵循开关。遇到不一致时标记问题并在停止辅助后导出记录即可。

版本仍为 0.4.6／code23；客户端支持按 APK SHA 识别同版本修订，配套公网清单更新后可检查更新，也可手动覆盖安装。
