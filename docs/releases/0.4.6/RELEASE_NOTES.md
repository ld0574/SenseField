## 安装与使用

支持 Android 10（API 29）及以上的 arm64-v8a 设备。下载 `sensefieldv0.4.6.apk` 后覆盖安装现有听野，不需要卸载旧版；版本应为 0.4.6。当前包沿用原 Android debug 证书，已混淆且非 debuggable，作为队友测试交付；不代表取得正式发布凭据。

点击「开始辅助」，完成系统录屏授权后打开开心消消乐。消消乐识别在本机处理；录屏权限用于读取共享画面，悬浮窗权限用于高亮，通知权限用于辅助状态和问题标记。浮层不接收触摸，应用不会自动交换棋子。行从上往下、列从左往右，从整个棋盘左上角以 1 开始编号。结束后停止辅助，可在「测试记录与反馈」导出对应记录；画面仅本地保存，不自动上传。

详细体验步骤见[队友复测说明](复测说明.md)。
