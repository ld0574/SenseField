# 听野 0.4.6

当前候选使用 `0.4.6 / versionCode 23`，承接消消乐规则与 CV 改造。已发布的 0.4.5／code22 保留原包、标签、清单及历史验证记录；本版本使用独立交付目录 `output/releases/0.4.6/`。

消消乐根据元素身份、覆盖状态和规则权限核验交换，补充藤蔓和小鸟外观证据；藤蔓中的动物可参与配对，仍不可作为交换端点。新外观进入有界诊断归集，规则不明的格子继续弃权，可靠区域继续提供提示。加入有界 HUD 字形补充，修正部分任务数字 7 误读为 2，原图中 ICE 72／27 步的工程回放通过。保留整盘行列编号、交换高亮、目标收益排序和所选语音引擎。

## 使用方式

- 点击「开始辅助」，完成录屏授权后打开开心消消乐；画面在本机识别，棋盘自动确认。
- 高亮需要悬浮显示权限，浮层不接收触摸。可继续直接交换棋子；语音、悬浮显示和通知权限分别服务于提醒与辅助状态。
- 行从上往下、列从左往右，都从整个棋盘左上角以 1 开始编号。
- 数量、覆盖或交换权限未确认时，减少提示或弃权。准备建议描述靠近目标的机会，不保证下一步收益或通关。
- 不自动交换棋子。可随时停止辅助；语音引擎和语速继续在设置中选择。
