# 听野 0.4.3

版本：0.4.3／versionCode 20。支持Android 10及以上、arm64-v8a手机。主线完整包包括王者荣耀辅助、开心消消乐体验入口和默认关闭的AI助手。

发布入口：[听野0.4.3主线Release](https://github.com/ld0574/SenseField/releases/tag/v0.4.3-main)。已有`v0.4.3`由消消乐分支发布占用，故本次使用独立源码标签`v0.4.3-main`；APP版本名称与升级序号不变。该发布为普通Release。本次覆盖保留开始前的GitHub Latest入口，实际核对发布前后均为`v0.4.3-main`；队友的独立标签与附件保持原样。

## 本版更新

- 改善提醒音效与方位语音的衔接，提前准备常用方位短句，并主动检查离线中文语音。
- 附近敌人、新头像、画面边缘和危险信号可分别选择四种内置音效；选择后立即试听，也可重复试听。保存后重新开始辅助生效。
- 首次完整说明可随时“跳过并开始”，底部始终保留开始入口；之后默认直接开始。仍支持按段听、暂停与继续，旋转后保留未完成位置。
- 改善系统大字布局、分组帮助与设置导航，两款游戏入口统一使用“开始辅助”。
- 合入消消乐分支截至 `5484401` 的修订：冰块／空位、标定检查、读不清反馈、行号标尺、录屏中断提示和播报审计；开心消消乐仍为体验功能。
- AI助手默认关闭，可在设置中按需开启。

小地图长方形预警范围尚未加入，本版保留现有范围、识别与敌人再出现规则。近期独立分支的新提交不自动计入这份APK，已合入来源以[消消乐合并记录的追加修订](../../../validation/MATCH3_LATEST_MERGE_0_4_3_2026-10-07.md)为准。

## 安装与使用

在上述发布页的Assets中下载“听野v0.4.3 安卓安装包.apk”并安装；“听野v0.4.3 使用说明.txt”提供操作步骤。附件下载文件名分别为`sensefieldv0.4.3.apk`和`installation-guide.txt`，GitHub显示中文标签。

1. 打开听野，选择游戏并点“开始辅助”。完整说明可直接跳过，以后也能在设置里按段重听。
2. 按页面提示完成本次截屏授权。悬浮窗用于提示层或助手小圆点，通知用于后台运行状态及暂停／停止入口；小地图识别和核心预警在手机本地处理。
3. 先到“设置 → 配置与调参”测试声音和振动。若缺少离线中文声音，使用“管理离线中文语音”进入系统设置，安装或选择可用的中文声音。
4. 结束后停止辅助，需要反馈时在“测试记录与反馈”导出日志。手机明显发烫时暂停并待其冷却；不同手机、耳机与语音引擎的效果可能不同。

主线已有同签名、升级序号不高于20的版本可覆盖安装。已安装消消乐独立分支0.4.30／0.4.31等更高升级序号版本的用户，请继续使用对应发布，不卸载后降级到本包。画面助手开启后须单独同意上传问题和截图；助手关闭时不影响本地预警。
