# 听野 0.4.8 公开测试版

Android 10 及以上，arm64；版本名称 0.4.8，内部版本号 30（2026-11-04 客户端修订）。

## 本次变更

- 移除每次播报后出现的“本机刚播出的提示音，响度……偏左／偏右”弹出提示和常驻状态条文案，同时移除相关计算。正常游戏播报、方位声音与振动继续使用原有通道。
- 消消乐动态语音收到单次合成失败时，先重连原语音引擎一次；重连失败或再次出错后才尝试其他离线中文引擎。保留用户的引擎、音色和语速设置，不重播已经过时的交换建议。
- 开发联调改用独立诊断助手，不再复用与具体 Release 混淆映射绑定的旧测试包；普通用户的应用内诊断导出入口继续保留，诊断助手不打入公开 APK。
- 修复澎湃 4／Android 17 上授权成功后被诊断自检自动拉回授权页的问题；可选读屏服务未开启不再打断游戏。系统结束共享后保留状态，等待用户主动重新授权。
- 两款游戏均在授权页恢复前台并取得焦点后启动截屏服务；取消可重试，旋转保留尚未交接的授权结果，同一授权仅使用一次。
- 合并 `feature/jev-l2-judgment` 分支：接入消消乐方位呈现、播报说明、局面朗读和强度相关改进，并保留原有提示连续性修复。
- 合并主分支最新诊断隐私修复：画面采集默认关闭，诊断包附带隐私说明，修复录制临时文件句柄。
- 游戏识别资源改为首次使用相应游戏时下载，不再将自训模型和学习模板打进 APK；支持进度、取消、续传、完整性校验、版本隔离和离线复用。
- 模型采用独立分发，服务端签发短期下载凭证，APK 不包含服务器签名密钥或模型供应商 Key。
- 修复更新核验同时比较显示版本名导致误拦截的问题，升级顺序与 Android 的 `versionCode` 一致；大小、SHA-256、包名、清单版本和签名检查继续执行，失败显示具体原因。

## 安装前提

本版依赖游戏模型下载服务。现有服务器沿用 `/data/wwwroot/sf/` 原地更新，保留私有配置、运行数据和已有 Nginx 站点；步骤见 [服务端更新说明](SERVER_UPDATE.md)。只在缺少 `/v1/game-models/` 路由时补充该路径，不重新初始化站点。下载通过后可离线使用本地游戏识别，画面理解仍需联网。

正常从 0.4.7 或 0.4.8 / code28、code29 升级可使用同证书覆盖安装。已有 0.4.9 / code26 预发布版的用户，应直接下载 APK 手动覆盖安装本包；其旧版应用内更新器会因版本名称降低而拒绝安装。本包的 code30 高于 code26，不需要卸载应用。

已部署 2026-11-03 完整服务包的服务器，本次客户端修订无需再次更新 Python、模型或 Nginx。

## 验证与发布边界

APK 为同证书签名 Release；最终大小、SHA-256 及配套更新清单以同批交付的 `SHA256SUMS.txt`、`latest.json` 和安装说明为准。同版本修订需要同时替换 Gitee 附件与网站清单，先核对下载字节，再更新清单。

本轮客户端修改后，1,310 项 JVM 回归、Debug 构建及 lint 通过。独立诊断助手已在 K50U 的 code29 Release 上成功导出并校验三份既有记录；诊断收集的 11 项 Python 回归通过。删除功能对应的旧测试已一并移除。

此前澎湃 4／Android 17 真机已验证取消后重试、启动王者、横屏采集及停止；这些既有结果不表示本轮新包完成了完整对局、语音听感或全机型验收。

GitHub 的同版 Release 覆盖为本次修订并继续作为 Latest。Gitee 附件和网站清单由维护者同步，先核对附件下载字节，再替换配套 `latest.json`。私有游戏模型不作为公开 Release 附件。
