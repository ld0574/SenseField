# 听野 0.4.8 公开测试版

Android 10 及以上，arm64；版本名称 0.4.8，内部版本号 28（屏幕授权兼容修订）。

## 本次变更

- 修复澎湃 4／Android 17 上授权成功后被诊断自检自动拉回授权页的问题；可选读屏服务未开启不再打断游戏。系统结束共享后保留状态，等待用户主动重新授权。
- 两款游戏均在授权页恢复前台并取得焦点后启动截屏服务；取消可重试，旋转保留尚未交接的授权结果，同一授权仅使用一次。
- 合并 `feature/jev-l2-judgment` 分支：接入消消乐方位呈现、播报说明、局面朗读和强度相关改进，并保留原有提示连续性修复。
- 合并主分支最新诊断隐私修复：画面采集默认关闭，诊断包附带隐私说明，修复录制临时文件句柄。
- 游戏识别资源改为首次使用相应游戏时下载，不再将自训模型和学习模板打进 APK；支持进度、取消、续传、完整性校验、版本隔离和离线复用。
- 模型采用独立分发，服务端签发短期下载凭证，APK 不包含服务器签名密钥或模型供应商 Key。

## 安装前提

本版依赖游戏模型下载服务。现有服务器沿用 `/data/wwwroot/sf/` 原地更新，保留私有配置、运行数据和已有 Nginx 站点；步骤见 [服务端更新说明](SERVER_UPDATE.md)。只在缺少 `/v1/game-models/` 路由时补充该路径，不重新初始化站点。下载通过后可离线使用本地游戏识别，画面理解仍需联网。

正常从 0.4.7 升级可使用同证书覆盖安装。已有 0.4.9 / code26 预发布版的用户，应直接下载 APK 手动覆盖安装本包；其旧版应用内更新器会因版本名称降低而拒绝安装。本包的 code28 高于 code26，不需要卸载应用。

## 验证与发布边界

APK 为签名 Release，大小 17,746,816 bytes，SHA-256 为 `a185b07d33d4a21f5c2235a6926b31203e32db0b696afb34ae51eeb2326c20ca`。

1,330 项 JVM 与 60 项相关 Python 回归通过；分发修订另通过 40 项 Python 与 12 项 JVM 更新策略检查。澎湃 4／Android 17 真机已验证取消后重试、启动王者、横屏采集及停止；该结果不代表完整对局与全机型验收。

2026-11-03 公网检查中，原有 `/health` 正常，新的模型下载路径返回 HTML 404。测试手机预置了模型缓存，因此生产首次下载仍待服务端更新后确认。本版先发布为 GitHub 公开测试 Release，保留 0.4.7 为 Latest；网站更新清单仍按 Gitee 附件核验流程另行更新。私有游戏模型不作为公开 Release 附件。
