# 听野 0.4.9 测试候选

Android `versionCode 26`，支持 Android 10 及以上的 arm64 设备。本版尚未公开发布，当前公开版仍为 0.4.7。

0.4.8 / code25 曾用于社区功能的开发配置；主分支随后升至 0.4.9 / code26，以高于可能已安装的测试包。本次沿用该版本配置，0.4.8 未在 GitHub 公开发布。

- **消消乐语音连续性**：普通棋盘变化时，已经开始的交换提示会说完，再根据最新画面给出下一条提示；失效旧框及时隐藏，尚未开始的旧语音取消，停止辅助或出现弹窗仍立即停声。
- **竖屏识别恢复**：消消乐辅助运行时也检查画面是否持续到达，断帧进入原有恢复流程并留下诊断记录；恢复失败时提示重新授权。
- **社区图文交流**：应用内可浏览帖子、发帖和通过系统相册选择配图，也可在浏览器打开社区测试页；默认接入已配置的社区测试服务。
- **更新交付校验**：构建时检查版本序号高于可读取的线上清单；APK 下载地址与更新清单保持同源。打包与核验版本从 Android 配置读取，避免继续生成旧版本名称的交付物。

## 验证范围

本次消消乐合并已完成 715 项 JVM 回归、Debug 和测试 APK 构建，以及 Release R8 混淆检查，均通过。上述结果不代表新包已完成真机验收；真机复测和公开下载核对仍需对应实际成品另行记录。

0.4.9 打包适配、更新清单、内置语音与社区相关的 92 项 Python 测试，以及公开仓库检查相关的 15 项 Python 测试通过。Release 构建与 lint 检查完成，lint 为 0 错误、39 警告。

本机签名证书已与 0.4.7 实际 APK 核对一致；0.4.9 的 Release 签名、版本及包名、不可调试属性、arm64 原生库与 16 KB 对齐、模型哈希和 856 条内置语音文件均通过成品核验。候选包位于 `output/releases/0.4.9/sensefieldv0.4.9.apk`，文件大小、SHA-256 与源码回执随包生成；本地候选不改变公网更新清单。

建议复测消消乐提示是否说完、长时间运行是否持续识别，以及社区登录、选图发帖和浏览。社区及助手需要网络；社区服务的可用性应在实际使用时确认。
