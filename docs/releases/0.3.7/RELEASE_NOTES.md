2026-10-03，版本 `0.3.7 / versionCode 15`。公开下载仍为 [0.3.5](https://github.com/ld0574/SenseField/releases/tag/v0.3.5)。

## 本版变化

减少诊断截图和识别前的重复复制，提醒频率和事件截图窗口沿用上一版。

## 安装与使用

支持 Android 10 及以上、arm64-v8a，可覆盖安装已有同签名版本。

1. 开始辅助前，先试听并确认媒体音量与语音。短音区分左右，上下方位请听语音，震动仅提醒附近。
2. 发现提醒不对时，在通知中点击「标记问题」；结束后到「测试记录与反馈」导出日志。
3. 比较发热时，使用同一手机、相近起始温度、相同充电与游戏设置，并记下实际版本和时间。

交付时已做代码和模拟器检查，手机温升与真实玩家效果待复测。交付后的两局真机记录仍显示明显发热，见[0.3.7 两局热反馈](../../../validation/HEAT_RETEST_0.3.7_2026-10-03.md)；复制优化不能作为降温通过的证据。
