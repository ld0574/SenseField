# 听野 0.3.5

2026-10-02 公开体验版。[历史下载入口](https://github.com/ld0574/SenseField/releases/tag/v0.3.5)；最新公开版见 [0.3.8](../0.3.8/RELEASE_NOTES.md)。

听野通过方位语音、提示音和震动，帮助低视力玩家留意《王者荣耀》里的附近敌人信息。当前优先面向中央视野仍能支持游戏操作、但周边视野受限的玩家。

## 这一版的变化

- 调整持续运行的处理节奏，兼顾提醒体验和手机负担。
- 新增「标记问题」；开启保存游戏画面后，可留存提醒前后的问题线索，方便反馈误报、漏报或方向问题。
- 保留开始前的提醒说明与试听，帮助理解语音、提示音和震动的含义。

## 下载与安装

目前支持 Android 10 及以上的 64 位安卓手机。

- 手机直接安装：下载下方 APK 文件。
- 微信转发或需要使用说明：下载「安装包 ZIP」，解压后安装其中的 APK。

已安装旧版的玩家可以直接覆盖升级。

## 怎么使用

1. 打开听野，选择《王者荣耀》，按页面提示完成授权。
2. 先试听语音和震动，确认自己能听见、感觉到，再开始辅助并返回游戏。
3. 游戏结束后停止辅助；也可以在设置里调整语音、提示音和震动。

方向以游戏小地图为准，以你的位置为中心。语音是当次提醒，并不会持续播报敌人的位置；你或敌人随后移动，后来看到的位置可能不同。提醒仍需要结合自己的判断。

识别在手机本地进行。游戏画面是否保存由你选择，记录不会自动上传。若希望留存问题线索，可先在设置开启「保存游戏画面」，异常发生后及时点通知中的「标记问题」，并记下游戏时间；结束后导出记录，交给协助体验的负责人核对。采样记录可能不完整。

当前为公开体验版，提醒仍可能漏报或出现方向偏差。建议先试听、短时体验，观察提示是否有帮助、手机温度是否舒适，再决定是否继续使用。
