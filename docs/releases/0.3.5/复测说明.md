# 听野 0.3.5（Android code 13）复测

本版保留 0.3.4 的降负载策略，增加有上限的事件前后画面采样。没有更换模型或调整“附近”范围；3:07 的误报原因仍待新证据核实。

1. 覆盖安装本 APK，在“设置 → 测试记录与反馈”确认开启保存游戏画面。
2. 像平时一样双手操作，比较发热是否比 0.3.4 回升、提醒是否变慢或漏掉。尽量保持相近起始温度、亮度、画质和充电状态。
3. 有误报或漏报时，及时点采集通知中的“标记问题”，记下游戏内时间和提示方向。平时最多约每秒缓存2组缩略图，提示/标记时尽量保存前3秒、后2秒；片段有数量、内存、容量和时长上限，采样不等于录像。
4. 一局结束后停止辅助，再导出这局ZIP给开发者核对。明显烫手或不适时提前停止，不必硬撑。

代码测试与模拟器不能证明真机不会发烫，本轮需要原手机实际体验。
