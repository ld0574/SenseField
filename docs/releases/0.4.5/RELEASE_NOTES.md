# 听野 0.4.5

开心消消乐提供交换建议，并高亮需要交换的两颗棋子。本次补充冰块任务与静止冰层识别，优先提示当前能确认有消冰作用的交换，修复目标数字被截断的问题。消除动画期间撤下旧提示，局面稳定后重新推荐。

## 使用方式

- 点击「开始辅助」，完成录屏授权后自动打开开心消消乐；棋盘自动确认，无需提前手工标定。
- 高亮默认开启，首次使用需要悬浮显示权限；拒绝后仍可使用语音。高亮不接收触摸，可以直接交换棋子。
- 从整个棋盘左上角数起：行从上往下，列从左往右，都从 1 开始。区域名称不会重新编号。
- 设置中可以选择自己的语音引擎和语速。不自动朗读「画面不稳定」等临时状态。
- 银币、冰层及已确认的任务优先排序；可靠时附上「消除冰层」「收集银币」等短理由。饼干仅提供已确认的接近机会。

消消乐仍为体验版。冰花等复杂障碍、特殊组合和多步策略继续完善；没有可靠任务收益时会提供基础交换，不保证通关。王者提醒、现有离线音色及 AI 助手默认关闭保持不变。
