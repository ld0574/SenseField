# 听野 0.4.5

开心消消乐提供交换建议，并高亮需要交换的两颗棋子。本次修正稀疏棋盘定位，改进剩余银币、冰层和饼干等任务的交换排序。有可确认的直接收益时优先提示；暂时不能直接消除时，在目标数量与位置可靠的条件下提供靠近目标的准备建议。减少数量未读清时的播报替换。

## 使用方式

- 点击「开始辅助」，完成录屏授权后自动打开开心消消乐；棋盘自动确认，无需提前手工标定。
- 高亮默认开启，首次使用需要悬浮显示权限；拒绝后仍可使用语音。高亮不接收触摸，可以直接交换棋子。
- 从整个棋盘左上角数起：行从上往下，列从左往右，都从 1 开始。区域名称不会重新编号。
- 设置中可以选择自己的语音引擎和语速。不自动朗读「画面不稳定」等临时状态。
- 可靠时附上「消除冰层」「收集银币」等短理由。「准备消冰」「靠近饼干」表示围绕目标准备，本步不一定完成收集。

消消乐仍为体验版。冰花等复杂障碍、特殊组合和多步策略继续完善；准备建议不保证后续收益或通关。王者提醒、现有离线音色及 AI 助手默认关闭保持不变。
