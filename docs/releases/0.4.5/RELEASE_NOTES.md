# 听野 0.4.5

开心消消乐提供交换建议、高亮两颗棋子，并在依据可靠时附上简短任务理由。本次继续 0.4.5／code22，改进棋子身份与覆盖识别：未知格子暂不参与推荐，可靠区域继续工作；陌生元素自动留存有界诊断，不自动猜测玩法。保留所选手机语音引擎。

## 使用方式

- 主页点击「开始辅助」，录屏就绪后自动打开开心消消乐；取消授权可以重试，不需提前手工标定棋盘。设置与返回游戏选择位于底部。
- 「设置」里的语音引擎／语速独立成组；高亮与行列说明在「交换提示」中，下方是截图校准、棋子学习、点读与对应游戏的测试反馈。
- 「交换位置高亮」默认开启，首次使用可授权悬浮显示。拒绝后仍能使用语音；高亮不接收触摸，不需要开启读屏服务。
- 全棋盘左上角为起点：行从上往下、列从左往右，都从 1 开始；区域名称不会重新编号。例如「右下区域，第 5 行，第 4 列和第 5 列交换」。
- 真实交换、消除、弹窗、几何失效、旋转、录屏结束或超过 5 秒没有新帧时撤下旧提示；新局面确认后再推荐。无关区域的证据变化不打断仍有效的建议。
- 金罐、饼干、冰花及其它未知机制不当作普通动物；认出动物的脸也需要核对当前完整外观。未支持的目标回退为基础交换，不保证通关或全局最优。
- 不自动朗读「画面不稳定」等临时状态。动态坐标继续使用所选手机 TTS；王者提醒、离线音色及助手默认关闭保留。
