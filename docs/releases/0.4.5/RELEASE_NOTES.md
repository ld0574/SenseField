# 听野 0.4.5

开心消消乐会框出建议交换的两颗棋子，并用双向箭头连接；棋盘变化后更新。点击开始实时识别后自动打开游戏，棋盘自动确认；设置与高级工具分开。本次按试用反馈修正高亮显示、行号读音及语音设置复用，减少不必要的状态播报。

## 使用方式

- 主页点击「开始实时识别」，录屏服务就绪后自动打开开心消消乐；无需另点启动游戏或预先标定棋盘。授权取消可重新开始，旋转与返回不会重复打开游戏。
- 「设置」保留高亮和通用语音引擎／语速；行列说明按需展开。截图校准、棋子学习与点读位于折叠的高级工具中，原资料与偏好保留。截图载入时也会先自动定位棋盘。
- 「开心消消乐辅助 → 设置」里的「交换位置高亮」默认开启。首次使用可允许悬浮显示；拒绝后仍能听语音，也可以稍后在页面内重新设置权限。高亮不需要开启读屏服务，不影响游戏触摸。
- 全棋盘左上角为起点：行从上往下、列从左往右，均从 1 开始。区域名称仅帮助找位置，不会重新编号。页面保留这句说明，可点「听行列说明」试听。
- 横向交换例如「右下区域，第 5 行，第 4 列和第 5 列交换」；纵向交换例如「右上区域，第 2 行和第 3 行，第 6 列交换」。自动提示不再附带推荐总数。
- 交换、弹窗、点读模式、棋盘无法确认、旋转或录屏结束时撤下旧高亮；新局面确认后重新显示。超过 5 秒没有有效新帧也会撤下。部分设备若无法安全显示浮层，本局继续提供语音。
- 带空位／冰块的棋盘不再因此被判作看不清。消除过程中先撤下建议，局面稳定后再推荐；学习库中的自定义外观仍可点读，自动交换只使用已确认的普通动物匹配规则。
- 动态消消乐提示继续使用在「设置 → 语音引擎与语速」选择的手机离线中文语音引擎，保留原音源和当前语速，页面不限定引擎品牌。「行」按横排行号发音，页面文字不变。暂不稳定、检测到游戏弹窗等状态不再自动朗读，正常交换建议和手动点读保留。原有游戏男声、游戏向导女声、王者荣耀提醒和默认关闭的 AI 助手保留。
