# 听野 0.4.5

开心消消乐会框出建议交换的两颗棋子，并用双向箭头连接；棋盘变化后更新。本次修复大块障碍／布局空洞误作普通棋子、录屏尺寸下漏掉棋盘下部造成的整段无提醒，并移除启动游戏时逐个加载其他 APP 名称的卡顿路径。点击开始辅助后自动打开游戏，语音沿用所选手机引擎。

## 使用方式

- 主页点击「开始辅助」，录屏服务就绪后自动打开开心消消乐；无需另点启动游戏或预先标定棋盘。授权取消可重新开始，旋转与返回不会重复打开游戏。设置和返回游戏选择与王者一样位于页面底部。
- 「设置」中语音引擎／语速独立成组；「交换提示」内放高亮与可展开的行列编号说明，下方有截图校准与棋子学习、点读与反馈。原资料与偏好保留，截图载入时也会先自动定位棋盘。
- 「开心消消乐辅助 → 设置」里的「交换位置高亮」默认开启。首次使用可允许悬浮显示；拒绝后仍能听语音，也可以稍后在页面内重新设置权限。高亮不需要开启读屏服务，不影响游戏触摸。
- 全棋盘左上角为起点：行从上往下、列从左往右，均从 1 开始。区域名称仅帮助找位置，不会重新编号。「交换提示 → 行列编号说明」保留原文，可点「听行列说明」试听。
- 「测试记录与反馈」按游戏显示标题、问题示例与记录；消消乐可反馈交换推荐、高亮和播报问题，王者保留漏报／误报说明。删除仅影响当前游戏，无法确认归属的旧记录明确标注并保留。保存画面的偏好共用，两款游戏合计保留最近 3 局。
- 横向交换例如「右下区域，第 5 行，第 4 列和第 5 列交换」；纵向交换例如「右上区域，第 2 行和第 3 行，第 6 列交换」。自动提示不再附带推荐总数。
- 交换、弹窗、点读模式、棋盘无法确认、旋转或录屏结束时撤下旧高亮；新局面确认后重新显示。超过 5 秒没有有效新帧也会撤下。部分设备若无法安全显示浮层，本局继续提供语音。
- 带空位／冰块的棋盘不再因此被判作看不清。消除过程中先撤下建议，局面稳定后再推荐；学习库中的自定义外观仍可点读，自动交换只使用已确认的普通动物匹配规则。
- 大块彩色障碍与布局洞不参与普通动物交换。定位同时核对压缩截图及录屏尺寸，保留细暗边连接、恢复精确边界；诊断记录注明推荐在哪一步等待。仍保持 800ms 采样，不增加自动状态播报。
- 交换排序复用已有匹配结果，优先冰块邻接、长连及去重消除格数。当前尚未自动读取关卡目标，不宣称通关最优策略；银币、鸡蛋和复杂特效规则仍需补齐。
- 动态消消乐提示继续使用在「设置 → 语音引擎与语速」选择的手机离线中文语音引擎，保留原音源和当前语速，页面不限定引擎品牌。「行」按横排行号发音，页面文字不变。暂不稳定、检测到游戏弹窗等状态不再自动朗读，正常交换建议和手动点读保留。原有游戏男声、游戏向导女声、王者荣耀提醒和默认关闭的 AI 助手保留。
