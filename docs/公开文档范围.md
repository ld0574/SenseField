# 公开文档范围

更新日期：2026-10-16。

公开文档围绕当前产品、使用方式、技术实现和开发协作组织，入口见[文档索引](README.md)。

## 公开内容

- 产品介绍、用户需求、系统架构及功能设计。
- 当前版本的安装说明、更新摘要、构建与部署指南。
- 可复用的规则说明、训练工具、测试方法和空白记录模板。
- 保留来源署名的赛题资料与公开研究参考。
- 第三方素材来源、许可条件与必要的使用限制。

## 本地材料

原始录像、玩家信息、截图、标注、逐局测试、内部排障、阶段复盘和评审工作材料不纳入公开目录。历史工程材料在 `validation/private/` 中留档，由 Git 忽略；构建制品保存在 `output/`。

## 维护约定

1. 新公开文档同步维护 `.gitignore`、公开扫描器的文档清单和[文档索引](README.md)。
2. 公开内容准确描述当前行为，保留授权、网络、语音引擎与适配范围等实际使用条件。
3. 实测结论绑定对应制品与输入；演示、工程回归和独立用户效果分别记录。
4. 发布前检查相对链接并运行 `python3 scripts/check_public_repo.py`。
