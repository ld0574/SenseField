## 维护方式

1. 新文档默认由 `docs/**` 忽略。准备公开的文档单独核对内容，再将文件路径同步加入 `.gitignore` 和 `scripts/check_public_repo.py` 的允许清单。
2. 会议和访谈优先写成匿名概括；公开原话、截图、具体个人信息或第三方全文时，记录相应来源与授权范围。
3. 研究材料区分公开事实、团队判断和待验证问题；来源链接可访问，不把搜索摘要或页面缺失解释为事实不存在。
4. 提交或推送前检查实际文件、相对链接与公开仓库扫描结果；文档范围扫描通过不代表整仓扫描也已通过。

文档入口见[文档索引](README.md)，发布流程见[GitHub 发布检查清单](releases/GITHUB发布检查清单.md)。
