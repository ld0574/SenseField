# 视野记忆（Vision Memory）

## 产品定义

视野记忆不是敌方追踪或战术指挥。它把玩家本来能够看见、但可能无法持续观察或记住的小地图事件，重新编码成高对比视觉、简短语音和触觉线索。

第一版明确不提供兵线计时、路线推荐、打龙建议和全局“注意敌方打野”等策略判断。

## 事件状态机

```text
候选目标
   │ 连续三帧中至少命中两帧
   ▼
APPEAR ──持续检测──▶ TRACK
   │ 连续丢失三帧
   ▼
                    DISAPPEAR
                         │
                         ├─ 保存最后位置
                         ├─ 保存可靠的最后移动方向
                         └─ LAST_DIRECTION 残影保留 4 秒后清除
```

4 秒计时从确认进入 `DISAPPEAR` 时开始；在确认丢失前的短暂漏检不会提前消耗残影时间。

若残影仍保留时目标重新出现，会重新执行三帧中至少两帧的确认，再产生一次 APPEAR；短暂漏检未进入 DISAPPEAR 时沿用原确认状态。

采样中断、屏幕旋转或暂停会直接重置状态，不把技术中断误报成“敌人消失”。
自适应小地图定位器无法确认可用区域时，也会静默清除小地图轨迹；定位恢复后重新确认目标，避免把定位失败误认为目标消失。

## 信息输出

| 事件 | 视觉 | 听觉 | 触觉 |
| --- | --- | --- | --- |
| APPEAR | 红色高对比圆环 | 原有空间提示音 | 方向编码短震 |
| TRACK | 跟随当前头像 | 静默 | 静默 |
| DISAPPEAR | 最后位置、斜线与移动箭头 | 有可靠速度向量时播报“左上敌人消失，向下移动” | 方向编码短震 |
| LAST_DIRECTION | 4 秒内逐渐淡出 | 静默 | 静默 |

提示层不接收触控，并设置安全窗口标记以请求系统从截屏内容中排除；不同设备上的实际行为仍需真机确认。新安装默认启用新头像事件提醒；画面提示只有在用户授予 Android 悬浮窗权限后才会显示，声音和触觉仍可独立使用，提醒也可在设置中关闭。

## 当前相关性过滤

第一版只使用已经可靠获得的证据，不伪造“完整战场理解”：

- 视觉事件必须通过置信度门限和 `2/3` 帧确认。
- 触觉只在 APPEAR / DISAPPEAR 状态切换时触发，并有 500 ms 冷却。
- 消失语音必须同时满足“新鲜状态切换”和“具有可靠移动向量”，并有 2 秒冷却。
- TRACK 和残影刷新永远不重复播报。

“危险接近”需要先可靠识别玩家自身在小地图的位置。没有自身位置、相对距离和接近速度时，系统不得仅因检测到敌方打野就发出危险提醒。后续完整相关性评分至少需要：

```text
relevance = 距离 × 接近速度 × 危险区域 × 交战状态 × 用户偏好 × 新鲜度
```

任一关键输入缺失时应降级为视觉记忆或保持静默，而不是用固定规则猜测。

## MVP 边界

| 能力 | 当前状态 |
| --- | --- |
| 敌人出现 | 已接入实验视觉、空间声音和触觉通道 |
| 敌人消失 | 已接入最后位置、移动方向、条件语音与触觉 |
| 危险接近 | 等待自身位置检测后实现，当前不播报 |
| 死亡／复活关键状态 | 软件链路已接入，真实签名与独立留出集待完成 |

移动端工程可行性、功耗、发热、帧率和端到端延迟均以听野自身的实体机测量为准。
