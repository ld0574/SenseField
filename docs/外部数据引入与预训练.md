# 外部数据引入与预训练

外部公开数据可以减少从零标注的工作量，但只进入预训练和困难样本挖掘。最终验收仍使用团队自己录制、按整场对局隔离且从未参与调参的手机录像。

## 2026-09-27 来源审计

| 来源 | 页面信息 | 对本项目的直接价值 | 当前决定 |
| --- | --- | --- | --- |
| [Honor of Kings Minimap](https://universe.roboflow.com/zyhe/honor-of-kings-minimap/dataset/1) | 2,993 张、128 个数字类、CC BY 4.0；2,989 train / 4 val / 0 test；统一拉伸到 640×640 | 可尝试学习小地图头像和 HUD 的通用视觉特征 | **暂缓导入训练**：先取得 128 类语义映射、原始来源说明并检查重复图；现有划分不能用于评测 |
| [Honor of Kings 英雄检测](https://universe.roboflow.com/wdnmdc01/honor-of-kings-u8coa-j1otr) | 3,254 张、10 个英雄类、CC BY 4.0 | 可供未来主画面英雄检测预训练 | 不并入小地图敌人模型；英雄本体与小地图头像属于不同画面域 |
| [Honor of Kings 场景小集](https://universe.roboflow.com/qinghai-university/honor-of-kings-zymyb-mtjnn) | 122 张，草丛、塔、野怪、血条、英雄、小兵等 6 类，CC BY 4.0 | 可人工筛选成困难背景或未来主画面辅助数据 | 规模太小，不作为主训练集或验证集 |
| KPL／公开视频 | 量大，但多为赛事观察者视角并带转播包装 | 可做 HUD 变化预训练和困难样本挖掘 | 先核对平台与转播素材使用条件；不把帧、权重或衍生数据直接公开，也不用于最终手机端验证 |

Roboflow 页面上的 CC BY 4.0 标记要求署名、许可证链接和修改说明。该标记本身不能证明上传者对每一帧游戏画面拥有完整授权；正式公开数据、样例图或训练权重前仍需记录来源和权利说明。

## 导入门禁

外部数据只有同时满足以下条件才可进入训练：

1. 保存来源 URL、版本、下载日期、页面所示许可证和下载包 SHA-256；
2. 找到可读的类别语义，确认哪些框能映射为本项目的 `minimap_enemy`；数字类别不能直接全部合并为敌人；
3. 检查同图重复、相邻视频帧和跨 split 重复；重新按来源视频／对局分组，而非随机按图片拆分；
4. 保持原始宽高比。页面已经拉伸到 640×640 的版本只能用于预训练对照，不能用于测量真实手机 HUD 几何；
5. 抽查至少每类 20 个框，记录错标、漏标、友敌混淆和非游戏界面；
6. 外部验证集指标只作数据质量参考，不进入比赛验收结论。

## 私有下载和自动审计

通过 Roboflow 网页或团队账号下载 COCO 格式，解压到忽略目录。API key 只放在本机环境变量中，不写入命令历史、文档或 Git：

```text
data/raw/external/
└── honor-of-kings-minimap-v1/
    ├── annotations/
    ├── train2017/
    ├── val2017/
    └── test2017/
```

下载后先运行只读审计：

```sh
PYTHONPATH=python python3 -m mapassist.coco_dataset_audit \
  data/raw/external/honor-of-kings-minimap-v1 \
  --output build/external-audit/honor-of-kings-minimap-v1.json
```

报告会列出类别、各 split 的图片和框数量、分辨率、缺失文件、精确重复图片和跨 split 污染。`training_blockers` 非空时不得直接合并训练。

## 训练顺序

1. **定位器：**继续使用自录全屏和人工 `minimap_region` 边界。公开小地图裁剪图不能训练全屏位置定位器。
2. **表征预训练：**只有在 128 类语义映射确认后，才用外部小地图数据预训练头像／图标特征；不引用它的 4 张验证图成绩。
3. **二分类微调：**使用自录玩家 POV，把边框颜色、阵营关系和遮挡后的完整图标人工映射为 `minimap_enemy`，再微调现有 YOLOX Nano。
4. **伪标注：**对获准使用的公开视频低阈值推理，人工复核后才进入开发集；未复核预测不作为真值。
5. **最终验证：**使用全新的真人匹配录像和 Android 实体机。5–10 台设备可作为扩展目标；黑客松首轮先覆盖至少两种宽高比和 Android 13/14 各一台，再逐步扩大。

所有外部数据、抽帧和权重默认留在忽略目录。若比赛交付需要发布权重，先把使用过的来源、许可证、修改和署名补入 `THIRD_PARTY_NOTICES.md`。
