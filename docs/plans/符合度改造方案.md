## 0.4.0 验收与测量

0.4.0 历史 GLM 合成图与 Android HTTPS/WSS 的 CPU ASR/视觉联调通过记录见[安卓传输记录](../development/assistant-android-transport-test.md)。0.4.1 较早 MiniMax 成功单点、近期 MiniMax 空正文探针、当前 Qwen 合成菜单请求和真机触发链分别记录于[真机记录](../../validation/assistant/ASSISTANT_LIVE_0.4.1_2026-10-04.md)；尚无目标玩家独立验收、外部录音实声或受控温升通过结果，这些门禁保持“待测”。

1. **设置与撤销**：语音、画面、主动观察三个开关分别验证默认关闭/开启/关闭；关闭后以网关请求日志确认没有相应请求。确认必须在用户授权的截屏会话内运行，并检查会话结束/`onStop` 后录音和请求均停止。
2. **服务安全**：使用 HTTPS；网关仅接受配置的设备 Bearer 凭据；确认日志不含凭据、完整文本、音频或图像。扫描提交候选，运行 `python scripts/check_public_repo.py`；实际密钥只通过部署环境配置。
3. **模型与数据条款**：核对模型清单中的仓库、revision、文件哈希和许可证；在目标服务账户下记录图像数据用途/保留条款。未完成前不把服务商路径描述为适合敏感数据。
4. **语音物理时延**：使用外部录像标注用户说话起点、说话结束、真实静音、正在播报的助手音频和其真实停止时刻。脚本 `python -m mapassist.measure_assistant_latency` 只接受 `external_recording` 标注；按 session/turn/audio ID 报配对样本数、缺失数、P50/P95。外部可见的 `final_recognition_ms` 用于统计用户说完至 ASR 终态的 P95（目标 ≤1 s）；语音触发 HUD 问答以说话结束至首段有用回答的物理声音 P95 ≤4 s。缺值保留 unknown，不用 App 回调填入。
5. **分开服务指标**：旧服务器 ASR 对照的网关 `asr_ms` 从 utterance start 计至 final event 发出；`elapsed_ms` 是对应视觉提供商的服务时间，历史 GLM 数值与当前 compatible-provider 单点分别报告。都不是端到端“听见有用回答”的延迟，不互相替代。
6. **设备与体验**：记录手机型号、Android 版本、音频设备/路由、网络、开始温度、每 5 分钟温度/热档/电量、游戏帧率、错误/无关提示、漏答与中断。热/负载对照至少做 3 组 15 分钟运行；候选相对对照的电池温升增量门槛 ≤1°C、native processing P95 回归 ≤10%。实施前预先定义起始温度匹配范围（建议配对相差 ≤1°C）。实际能否听清、是否有帮助、是否妨碍游戏由参与者直接评价。
7. **近区与既有小地图门槛分开**：500 ms 是 near-zone 观测年龄预算；外部实声 P95 ≤500 ms 是陪同试点目标；两者都不等于严格最终门槛。既有门槛真实声音 P95 ≤250 ms、平均处理 ≥8 FPS、最大处理帧间隔 ≤2 s、冻结配置/parity/独立留出等保持不变；助手测量不为小地图指标背书，也不改变 `verified` 或 `release_ready`。

CSV 表头和计算规则见[0.4.0 Goal](../../validation/assistant/GOAL_0.4.0_2026-10-03.md)。`nearest rank` 的 P50/P95 只是对有效配对时差的统计；样本不足时报告数量与分布，不宣称通过。
