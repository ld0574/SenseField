# 消消乐棋盘校准改进

日期：2026-10-13。用户指出王者已有自动定位与训练模型，框选应优先用于消消乐。落实这一优先级：王者未提交的框选原型已撤回，当前模型、自动定位及已完成的调度／呈现改进保留。本轮完善消消乐现有校准工具，不增加每关手动操作。

## 发现的问题

审核基线为 `c6826e03f1213bd4929546300f0abd8f4695e07c`，版本 0.4.6／code23。

- “框选识别”读取的是已定位棋盘中的局部格子，不能修改整个棋盘边界。手动校准只有百分比输入，缺少直接框选、明确保存和恢复自动的操作。
- 载入截图时自动定位、采样、点读、保存模板均调用校准写入；仅试读一张截图就可能改变实时候选，且自动定位也被标成已校准。
- 预览只处理 `ACTION_UP`，没有接住 `ACTION_DOWN`；坐标直接按整个控件宽高换算，忽略图片实际缩放、居中和 padding。
- 整数百分比会使精确边界发生偏移；边界调整、行列变更和界面重建需要保留已选择的像素范围。

其中两个实际故障已通过新增 Android 测试在改动前复现：2 项执行，2 项失败。原始日志保留本地；不是依据猜测新增功能。

| 交付 | 完成条件 |

| 整个棋盘范围框选 | 截图预览支持拖框和两个对角点击，反向选择也有效；只修改当前截图草稿 |

## 使用方法

1. 开心消消乐辅助 → 设置 → 截图校准与棋子学习 → 选择游戏截图。正常截图仍自动定位，可直接试读。
2. 自动定位不准时展开“手动棋盘校准”，点“框选棋盘范围”，拖出整个棋盘或依次点两个对角。包含不规则边缘格和中间空位，再确认行列及网格。
3. 点击“确认网格并保存校准”才用于实时识别；“清除校准，恢复自动定位”撤销候选。“选取区域并试读”只读局部格子，不改变棋盘边界。

框选用于识别失败时的兜底。仅凭画面范围不能识别新元素或保证策略收益，也不要求玩家每局框选。不同宽高比的截图候选不跨屏幕拉伸；换局仍会重新核验。
