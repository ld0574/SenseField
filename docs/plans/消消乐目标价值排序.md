# 消消乐：按通关价值排序

## 目标

根据本关剩余任务，优先推荐能推进目标的合法交换。推荐价值需要通过任务计数变化与棋盘变化验证，不能只用三连数量、消除数量或最终过关结果代替。

2026-10-09 真机试用的第 42 关有银币、冰块和小鸡任务。原排序仅比较三连条数，同分时沿行列扫描顺序挑选；未读取目标栏，缺少任务相关性。游戏最终进入奖励画面是玩家结果，不构成推荐有效性的证据。

## 当前已实现的基础

- 保留合法交换集合；仍只对已确认的普通动物使用颜色匹配规则，不推断自定义棋子、银币、鸡蛋或特效组合的行为。
- 用已有三连计算结果，统计本次交换直接形成的最长连线、去重后的消除格数及相邻的已识别冰块数量。
- 实时与截图推荐共用排序：冰块邻接 → 长连 → 消除格数 → 连线数量；同分保留原稳定顺序。没有增加截图或推理频率。
- 诊断记录排序依据，明确标记 `local_one_move_level_goal_unread`。这只是局部规则，不宣称已选出通关最优步。

## 后续实现顺序

1. **自动确认本关目标与剩余步数。** 读取目标类型、剩余数量及完成标记，随关卡切换清空旧状态；同一目标在当前画面中确认后才参与排序。不能把棋盘上某种动物数量当作任务要求，或将看不清的数字补成零。当前没有可用的目标读取实现。
2. **补齐棋子与障碍的独立状态。** 区分动物颜色、可移动性、覆盖层和特效；鸡蛋与小鸡、银币与普通动物分别处理。现有单个字符的颜色矩阵不足以表达这些规则。每种新规则先明确可观察依据和适用范围，识别不确定时不参与特效或障碍收益推算。
3. **评估合法交换的任务收益。** 比较直接完成目标的可能性、减少未完成目标的数量、清理阻碍目标的区域和已确认特效收益，再结合剩余步数。对当前已经完成的目标不再计收集价值；重复覆盖的格子与目标只计算一次。随机落下的新棋子不能作为确定收益。
4. **保留可解释的短提示。** 高亮与语音消费同一条推荐；有可靠目标依据时可说明「优先消冰」或「收集小鸡」，没有可靠目标依据时继续提供基础交换。限制解释长度，不能使坐标播报进一步拖长。
5. **独立验证收益。** 为真实关卡标注任务、合法交换及合理的优先选择；分开验证识别、交换合法性和任务收益。记录建议动作前后的计数变化、实际是否采取建议、无关提示与打扰。玩家过关不直接计作算法通过。

## 验收边界

覆盖不同任务类型、已完成目标、剩余步数不足、未知数字、关卡切换、鸡蛋／小鸡、银币／冰块和多层障碍；每类规则都有独立用例，不能用测试自身的评分函数生成标准答案。

性能继续使用同机、同条件的受控对照。识别处理 P95 恶化超过 10% 或温升增加超过 1°C，不记患者试用通过。保持助手默认关闭，优先完善本地确定性链路；目标识别的运行方案确定前，不加入新模型或上传游戏画面。

未做训练、阈值扫描或封存视频读取。基础排序的工程回归不作为完整通关价值验收；历史评分、`verified`、`release_ready` 均按独立证据更新。
