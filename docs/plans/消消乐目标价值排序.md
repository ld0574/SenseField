# 消消乐：按通关价值排序

## 目标

根据本关剩余任务，优先推荐能推进目标的合法交换。推荐价值需要通过任务计数变化与棋盘变化验证，不能只用三连数量、消除数量或最终过关结果代替。

2026-10-09 真机试用的第 42 关有银币、冰块和小鸡任务。原排序仅比较三连条数，同分时沿行列扫描顺序挑选；未读取目标栏，缺少任务相关性。游戏最终进入奖励画面是玩家结果，不构成推荐有效性的证据。

## 2026-10-09 工程改造

本地目标读取、独立棋子状态、任务收益排序和收益观察已接入实时帧与截图工具，继续覆盖 0.4.5／code22。只在已确认的范围内给出任务相关理由，不宣称全关卡或全局最优策略。

- **读取与确认**：复用 800ms 录屏帧，在顶部小区域识别挂牌、剩余数字、完成勾与步数；三份不同时间的样本确认当前状态。未知数用 `-1`，不补零。关卡号能读出时随状态携带；数字、目标身份、布局失效或关卡／尺寸变化时作废旧确认。融合／抖动的挂牌不被误当成少了一个目标或全部完成。
- **类型与规则分开**：普通动物颜色、交换权限、物体类型和覆盖层独立保存。自动规则不依赖玩家学习库中的名字。当前视觉模板覆盖银币、已观察到的单层白色方块及鸡蛋／鸡窝的已见状态；其它颜色表面、层数、覆盖、特效或大型障碍不能按普通动物猜规则。银币和鸡蛋的交换能力未确认时，不作为交换端点。
- **目标收益排序**：先比较能否直接完成所有可靠目标、完成目标数、各目标剩余量中的贡献比例、确定性收集量及与任务相关的破障机会；再比较潜在特效与原有局部指标。最后一步不把未来特效当额外回合。已完成目标不计收益，交叉消除／重复目标去重，收益按剩余量封顶；保留可能留在棋盘上的特效格，不把随机下落或未验证爆炸计作确定收益。
- **简短解释**：高亮和声音消费同一条推荐，可靠时只追加“收集小鸡”“清除障碍”“靠近鸡蛋”等短理由。不能由孵蛋直接断言已经收集小鸡；不朗读临时识别状态。目标栏可读但尚待三份观测确认时撤下旧提示并等待，避免同一棋盘来回改播。截图工具只完整播放第一条建议，消除原先五次连续替换试听的问题。
- **验证反馈**：记录建议的棋盘／目标来源、预期任务收益下界与之后的目标计数变化。仅观察到准确的两格互换且只消耗一步时标记“可见交换相符”；没有手势证据，不能声称玩家实际采纳。看不到动作、多步、计数未知、重置或超时分别记为无法归因。基础推荐不提前清空待确认的原收益观察；可靠观察低于已预测的下界时，本会话停用该类型的收益声明，旋转仍保留停用，不调整阈值或训练模型。

固定模板约 106KB 原始 JSON，由明确提供的诊断画面中无用户信息的目标栏／棋盘区域构建；没有新视觉模型、联网或新增截图频率。目标栏位图和工作区复用，棋子模板只在当前帧的规范化特征变化时重新比较；缓存刷新的是当前观测，不复用旧帧时间。

故障回归已经通过手工标注的第 42 关数字、完成勾和棋子状态：银币 16、白色方块 46、小鸡 66、剩余 32 步等；实际投影选择了手工标注的第 6／7 行、第 7 列交换，在处理剩余方块的同时接近鸡蛋。切换到第 43 关未支持的大块障碍目标后清除旧理由并提供基础交换。它们是开发故障回归，不能作为独立准确率或真实通关价值的通过证据。

新增 23 项 JVM 规则／确认／收益观察检查；首次四项视觉批次的两处失败以及修正过程保留。完整门禁与最终制品以[本批记录](../../validation/match3/MATCH3_GOAL_VALUE_0_4_5_2026-10-09.md)为准。模拟器同组输入、两条路径交错对照，初次 P95 增加 17.7%，加入特征一致时的模板复用后为 9.3%；没有把软件对照写成 3×15 分钟手机温升通过。

## 此前局部排序基础

- 保留合法交换集合；仍只对已确认的普通动物使用颜色匹配规则，不推断自定义棋子、银币、鸡蛋或特效组合的行为。
- 用已有三连计算结果，统计本次交换直接形成的最长连线、去重后的消除格数及相邻的已识别冰块数量。
- 实时与截图推荐共用排序：冰块邻接 → 长连 → 消除格数 → 连线数量；同分保留原稳定顺序。没有增加截图或推理频率。
- 诊断记录排序依据，明确标记 `local_one_move_level_goal_unread`。这只是局部规则，不宣称已选出通关最优步。

## 原实施顺序及剩余范围

1. **自动确认本关目标与剩余步数。** 已实现当前挂牌布局和已支持图标的本地读取／确认；其它布局、类型及无法读取的关卡号保留未知，不沿用旧状态。不将棋盘上某种动物数量当任务要求。新的界面／设备仍需独立核对。
2. **补齐棋子与障碍的独立状态。** 已独立表达颜色、交换权限、物体及覆盖层，保留原矩阵作为确认／兼容投影。运行中已支持的视觉类型与仅在规则用例中表达的多层覆盖分开记录；其它复杂障碍／特效尚未自动识别，不参与未经确认的收益推算。
3. **评估合法交换的任务收益。** 比较直接完成目标的可能性、减少未完成目标的数量、清理阻碍目标的区域和已确认特效收益，再结合剩余步数。对当前已经完成的目标不再计收集价值；重复覆盖的格子与目标只计算一次。随机落下的新棋子不能作为确定收益。
4. **保留可解释的短提示。** 高亮与语音消费同一条推荐；有可靠目标依据时可说明「优先消冰」或「收集小鸡」，没有可靠目标依据时继续提供基础交换。限制解释长度，不能使坐标播报进一步拖长。
5. **独立验证收益。** 已有手工标注的故障图和纯规则用例，收益观察链路已实现；新的真实对局、实际是否采纳、外部声音、无关提示与打扰仍需独立采集。玩家过关不直接计作算法通过，缺少动作证据不会补成采纳或成功。

## 验收边界

覆盖不同任务类型、已完成目标、剩余步数不足、未知数字、关卡切换、鸡蛋／小鸡、银币／冰块和多层障碍；每类规则都有独立用例，不能用测试自身的评分函数生成标准答案。

性能继续使用同机、同条件的受控对照。识别处理 P95 恶化超过 10% 或温升增加超过 1°C，不记患者试用通过。保持助手默认关闭，优先完善本地确定性链路；目标识别的运行方案确定前，不加入新模型或上传游戏画面。

未做训练、阈值扫描或封存视频读取。基础排序的工程回归不作为完整通关价值验收；历史评分、`verified`、`release_ready` 均按独立证据更新。
