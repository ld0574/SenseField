# 团队协作与本地运行

本文面向参与听野开发的成员。命令默认在仓库根目录执行；产品使用见 [README](../../README.md)，演示准备见 [路演指引](../demo/录制说明.md)。

## 环境准备

Python 需要 3.10 及以上版本。创建本地环境并安装测试依赖：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
```

Android 工程位于 `android/`。使用 Android Studio 打开该目录，通过 SDK Manager 准备 SDK Platform 36、NDK `28.2.13676358` 与 CMake `3.22.1`。应用支持 Android 10 及以上的 arm64 设备。

模型权重、原始录音、标注数据库和签名材料保存在团队认可的私有渠道。构建前按仓库中的 metadata 准备匹配模型与内置语音资源；公开源码不包含全部运行素材。不要将这些文件提交到 Git。

## 本地验证

```sh
PYTHONPATH=python python -m pytest -q
cmake -S native -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native -j4
```

可自行生成合成素材验证桌面链路：

```sh
python -m mapassist.synthetic --output-dir build/synthetic
python -m mapassist.replay build/synthetic/fixture.mkv \
  --profile build/synthetic/profile.json \
  --output build/synthetic/predictions.jsonl
python -m mapassist.evaluate \
  build/synthetic/predictions.jsonl build/synthetic/labels.json \
  --output build/synthetic/report.json
```

合成回放用于验证程序链路。真实游戏效果按对应设备、游戏版本和独立对局记录。

## Android 构建与试装

在 Android Studio 中连接已开启 USB 调试的设备并运行应用，或执行：

```sh
bash scripts/install_android_debug.sh
```

多设备时用 `--serial '<设备序列号>'` 指定设备。脚本进行开发构建、测试和安装；正式签名包使用 `bash scripts/build_android_preview.sh`，准备方式见 [内置语音与正式包构建](offline-speech.md)。

安装后选择游戏，按界面完成通知、录屏和悬浮窗授权。王者荣耀使用横屏与整个屏幕共享。助手需在应用中单独开启，并按需授权麦克风和画面共享。暂停和停止可从应用或持续通知操作。

消消乐相关改动按 [自动回归](match3-regression.md) 验证。诊断采集使用 [ADB 收集工具](android-adb-diagnostics.md)，原始日志与截图放在 `validation/private/`。

## 标注与数据分组

只接受人工复核的 HD 画面。每场录像整体属于同一分组；参与调参、规则修改或样例分析的对局属于开发数据。`video9`、`video12` 是封存留出，不查看内容、不运行模型或读取预测；启封须遵循独立评测流程。

由一台主机运行标注服务，同伴通过同一可信局域网协作，不复制数据库并行修改。单机示例：

```sh
PYTHONPATH=python python -m mapassist.annotation_server \
  --dataset hd-review=data/private/hd-review \
  --host 127.0.0.1 --port 8765 --open
```

替换为已准备的审阅队列。该工具没有公网账号认证；局域网协作时仅向可信网络开放。进度保存在队列的 `annotations.sqlite3`，运行中不要手工编辑或复制数据库。

| 状态 | 含义 |
| --- | --- |
| `accepted` | 人工确认建议框正确 |
| `corrected` | 人工修正或补充目标框 |
| `negative` | 对局画面中确认没有目标 |
| `excluded` | 选人、加载、结算等非对局画面 |
| `skip` | 遮挡或细节不足，无法判断 |

敌人头像和玩家自身头像分开标注。机器建议仅辅助审阅，不直接充当真值。数据导出、训练和部署的一致性要求见 [训练流程](../../training/README.md)。
