# 消消乐自动回归

提交消消乐改动前先在开发机验证识别、推荐、播报与高亮，不能只等玩家开局发现问题。当前入口为 `scripts/verify_match3_regression.py`，输出日志、用例数量、失败原因、源码摘要与实际测试包摘要到 `validation/private/`，不上传用户资料。

## 日常检查

```sh
python3 scripts/verify_match3_regression.py
python3 -m unittest discover -s tests -p test_match3_regression_gate.py
```

默认运行完整 JVM 回归，不连接手机。除了固定故障用例，交换逻辑通过独立的三格窗口规则校验 512 组棋盘、镜像和转置；覆盖 6～9 行列、障碍、空洞、未知字符、单行／单列及原矩阵不变。

外观标签与交换规则分开：自动推荐使用明确的普通动物颜色；自定义模板可识别／点读，不凭名称或相同外观推断特殊组合、障碍可移动性。加载新目录也不能改变正在使用的模板名称。

## 合包前检查

启动一个 arm64 Android 模拟器，准备已有签名的四个环境变量：`SENSEFIELD_KEYSTORE_PATH`、`SENSEFIELD_KEY_ALIAS`、`SENSEFIELD_KEYSTORE_PASSWORD`、`SENSEFIELD_KEY_PASSWORD`。沿用交付证书，不新建签名，不将密钥写入命令记录或仓库。需要时设置 `JAVA_HOME`、`ANDROID_HOME`。

```sh
python3 scripts/verify_match3_regression.py --mode full --serial emulator-5554
```

这条命令依次运行：

1. 完整 JVM 回归。
2. Debug 页面、合包、原生位图／动态 TTS 回调／真实 MediaProjection 测试：长句超过 4 秒、慢语速、引擎初始化、缺失回调、替换和迟到回调、窗口像素过滤、权限拒绝、停止持帧、旋转、关卡变化、5 秒无帧及模板资源释放。
3. 正式 Release 构建、裁剪、包校验与 lint。
4. 安装同一份 minified Release 到模拟器，检查消消乐主页、设置／语音页、高级区折叠与旋转恢复、取消系统录屏授权后可重试，再验证：持续高亮、实际交换手势穿透、局面更新、弹窗、消除中暂不推荐、重新确认 8×6 几何；同时运行已有离线音频、JNI、ASR 依赖和诊断工作回归。
5. 收集实际模拟器截图、主页／设置／高级工具画面和状态检查点。报告的 `passed` 只表示上述工程检查通过。

脚本只接受 `emulator-*`，检测到正在运行的辅助会话就停止。不会自动操作患者手机、发布包或生产服务器。ADB 的退出码不能代表仪器用例成功；必须收到完整的 `OK (...)`，崩溃或 `INSTRUMENTATION_FAILED` 都算失败。

历史诊断 JPEG 可通过 `--fixtures /绝对路径/诊断截图目录` 明确提供，进入测试 APK，不进入正式 APK。没有提供时，历史图片用例标为跳过；不能将其写成通过。不得把封存录像目录传给这个参数。

## 失败与交付

任何失败先看报告里的对应日志并修复，再运行必要的后续检查。保留首次失败记录，不通过扩大生产阈值、降低采样频率或删用例掩盖问题。设备调度造成的等待预算与产品时效指标分别记录。

门禁通过后才运行 `scripts/build_android_preview.sh` 生成唯一的 APK 和匹配清单，并核对交付摘要与测试摘要相同。页面说明、版本号和 Release note 不能代替检查。

外部录音中的实际发音／完整性、患者找格体验、Android10／13 的系统差异，以及同机条件匹配的 3×15 分钟温升仍需要独立验证。合成画面与软件回调不作为这部分证据。评分、`verified`、`release_ready` 按实际门禁记录。

## 消消乐日常入口

消消乐主页只保留运行状态、开始、停止和设置。点击「开始实时识别」取得整屏录屏授权；服务确认投影与帧监听已就绪后再打开游戏。请求标识随旋转保留，成功后先消费再打开，返回听野不会重复启动；取消授权可直接重试。已运行时不会重复申请或消费录屏令牌。

实时链路自动确认棋盘范围、独立行列数及连续三帧几何，仍按当前画面核验，不能用保存的参数替代确认。「设置」先独立呈现语音引擎／语速，下方保留高亮、行列说明、截图校准与棋子学习、游戏内触屏点读及反馈；不再套一层折叠的高级工具入口，语音页面不限定品牌。截图导入也先自动定位，失败后才需手动处理；工具页的手动参数仍按需展开，原学习库和语音偏好保留，不清空用户资料。主页设置与返回游戏选择采用与王者相同的底部布局。

完整门禁现在包含 `Match3UiInstrumentedTest`，同时对 Debug 与最终 Release 的真实布局、授权取消和旋转恢复作检查。新页面继承系统大字和读屏标签；界面检查不替代实际游戏跳转、玩家可用性或发热验证。

实时与截图使用同一套局部排序，额外的统计复用已有匹配结果：冰块邻接、最长连线和去重消除格数。原合法交换枚举及独立三格校验器继续保留，排序用例另验证底部冰块相关走法、长连、交叉去重与输入不变。目标栏与复杂棋子规则尚未接入，后续范围见[通关价值排序](../plans/消消乐目标价值排序.md)。
