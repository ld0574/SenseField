# 0.3.8 温控介入与通知入口

日期：2026-10-03。本地候选 `0.3.8 / versionCode 16`，公开 Release 仍为0.3.5。依据[0.3.7两局反馈](HEAT_RETEST_0.3.7_2026-10-03.md)，优化复制已将上下文复制降到约4 ms，但完整native帧处理仍平均约296/317 ms；第二局电池温度42.2→43.9°C，系统thermal始终为none。上一版直到第二局270.980秒才进入WARM。交付时尚未取得本轮真机复测，交付后主观反馈见下文。

## 改动

| 策略 | 0.3.7 | 0.3.8 |
| --- | --- | --- |
| 电池WARM介入／退出 | 43.0／42.0°C | 40.0／39.0°C |
| 电池HOT介入／退出 | 45.0／44.0°C | 42.0／41.0°C |
| NORMAL完成后休息 | max(40 ms, C/4)，最多150 ms | 相同 |
| WARM完成后休息 | max(80 ms, C/2)，最多250 ms | max(120 ms, 3C/4)，最多400 ms |
| HOT完成后休息 | max(100 ms, 3C/4)，最多350 ms | max(180 ms, C)，最多600 ms |

C是服务一次获准处理的实际墙钟成本，包括native及其后诊断／提示工作。以上电池温度是应用降载触发点，不是硬件安全限值或机壳温度；Android热状态仍可独立提高模式，缺失读数保留已有模式。一度滞回避免反复升降档。每次新设备样本最多下降一级，识别状态重置不再重复消耗同一份温度样本。

旋转、暂停、黑帧和截屏恢复只重置识别／输出状态，保留同会话负载截止时间和温度采样水位。新会话仍重置计时时钟，诊断记录器立即取设备样本，首帧准入时读取最新热状态。跳过的帧立即关闭，保持最新图像采集与健康检查，不睡眠、不排队旧图像。

通知折叠文案改为“展开通知可标记问题、暂停或停止”，热状态下直接提示“温度较高，提醒可能变慢；展开可标记问题”。展开后保留解释和三个动作，“标记问题”排第一。移除通知内的模型／profile标识和调试计数；这些信息仍在诊断日志。反馈页面补上展开通知的方法。0.3.7截图只证明通知折叠，零条标记不能证明按钮缺失。

识别输入padding显式沿用模型的ncnn Option（2线程、OpenMP blocktime 0及既有精度配置），避免该调用默认构造另一份Option。共享padding helper与Android合成parity测试同源；原ROI、RGBA→BGR、resize尺寸和114填充保持一致。没有据此宣称节省的能耗或温度。

- 163项Android JVM测试通过，含实际42.2°C／thermal NONE开局、40.9°C提前降载、温度滞回、deadline重算及极大耗时的溢出保护。
- `assembleDebug`、`assembleDebugAndroidTest`、`lintDebug`通过。Android 13 arm64模拟器4项instrumentation通过。
- Android 13 arm64模拟器96组320/512合成ROI、stride及padding对照，与旧默认Option预处理结果逐元素bit-identical，含空输入和超尺寸拒绝；没有运行游戏或封存录像。
- Android 13模拟器通过实际应用授权界面启动采集，在展开通知点击“标记问题”，随后点击“停止”。日志确认1条`user_marker`、来源`notification`及正常结束；三个动作可见。该短测为竖屏应用页面，帧／图片计数均为0，只验证通知到标记记录的链路，不证明游戏事件前后画面保存或vivo系统上的呈现。证据在ignored `build/score-recovery/0.3.8/`，本次模拟器已关闭。

## 延迟代价与复测

按已记录约301.5/323.6 ms的平均服务处理成本计算，新WARM帧间隔约528/566 ms，HOT约603/647 ms；这是调度公式推算，不是0.3.8实机测量。处理频率降低会影响多帧确认和快速目标的捕获，可能增加提醒延迟或漏掉短时事件。500 ms是单条观察的年龄上限，不能当作采样周期或实际发声延迟；严格最终250 ms／8 FPS门槛没有降低。

手机充分冷却后先做短时检查：确认展开通知的“标记问题”能产生`user_marker`，双手操作时提醒正常，再看热档下方向与时效。若仍烫手，停止连续测试。后续温升对照使用相同设备、相近起始温度、相同游戏／音量／充电／热点设置；无需额外在本机录屏增加负载。有条件时用另一设备录制实际声音与画面，并保留诊断ZIP。不能将本轮代码和模拟器检查当作真机降温通过。
