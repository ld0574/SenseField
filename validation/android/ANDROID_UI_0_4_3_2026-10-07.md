## 改动与范围

沿原生 Java/View 与现有听野 Logo、暖白／深青品牌改进。按最新反馈，游戏选择恢复熟悉的左侧文字、右侧操作卡片，两款入口统一「开始辅助」，消消乐副标题去掉「· 乐元素」。普通字号优先并排，实际文字放不下时重排。运行主页明确状态、开始与停止；设置按「授权与运行」「提醒与学习」「实验与反馈」分组。

集中实现 24／20／18／16sp 字体角色、20dp 页边距、24dp 组间距、12dp 控件间距、主操作最小 64dp、次操作与帮助触区最小 56dp。正文完整遵循系统字号，移除此前 150% 上限；Android 14 的非线性字体缩放由系统处理。试听最多两列，表单保留字段标签；返回栏和帮助关闭用图标配合中文无障碍名称。

上下文面板保留原说明名称、正文与顺序，以自然段和句群排版；一次点击打开对应分组，无「查看完整说明」跳转。手机底部面板，宽屏保留至少 360dp 设置区域才使用侧栏。完整说明保留首次学习、后续跳过、按段听、暂停继续；旋转／离开后保存未完成句子，返回时不自动播放。短横屏的底部播放区采用左右排布，长状态可滚动。

输入、光标、选择项、展开及滚动位置随页面恢复。弹窗复用原按钮与回调。220ms 面板动效遵循系统动画开关，隐藏时取消；旧关闭或播放回调不能影响新轮次。助手设置仍默认关闭；实验声音设置移至配置页，保留原偏好键。助手面板的文字可滚动，展开时不透明，收起白点视觉为 36dp、触区 56dp。

本轮保留核心预警、识别参数、模型、音频路线及音频行为。未训练、未扫描识别阈值、未读取封存视频、未连接或部署助手服务，未发布 Release。

## 截图审视与修订

保留 0.4.2 的游戏选择、王者主页、设置三张实际对照截图；0.4.3 使用 360×800dp、普通字号的同三张图。截图审视确认游戏卡片恢复熟悉构图，副标题不再在「乐元素」处换行；状态与开始操作可在主页首屏看到，设置导航名称、摘要和箭头分层。正常字号、320dp／200%大字及短横屏的页面末尾另行审视；试听末项、配置实验开关、导出／删除、说明底部播放区完整可达。

此前草稿的横屏 200% 播放区占用过多高度，已改为左右排布并保留独立状态滚动。早期截图存在启动帧捕获时序问题，已补绘制提交等待与空白图断言。早期反馈页重建后被输入焦点拉到底部，已在最终布局完成后恢复滚动。

实际审视 320dp／200% 弹窗发现确认按钮被长消息挤出屏幕，而旧文字布局断言未能发现。现在保留原生按钮区标识，由重排容器提供实际操作区所需高度，让正文在剩余空间滚动；按钮和原回调不复制。新增整个按钮宽高均在屏幕可见的断言，11 格弹窗增量复测全部通过。

首轮 79 项中系统授权返回一项失败，原因是测试注入 Back 事件使用零时间戳；改为单调时间戳、键盘输入源并检查注入成功，重新完整执行 79 项通过，实际系统授权返回和键盘关闭均已覆盖。捕图流程中的 `Integer.MAX_VALUE` 滚动溢出和下一次布局焦点拉回亦已修正；只在测试捕图期间屏蔽子控件焦点并计算精确滚动末尾，布局稳定后再次核对。上述失败及修复日志分别保留，不计入最终通过数量。

`prototype/`、`screenshots/`、`matrix-preliminary/`、`landscape-extreme/`、`landscape-repaired/`、`page-captures/` 和早期 instrumentation 日志为过程证据。最终图库的页面截图来自稳定补拍，弹窗来自修复后专项；统一汇入 `matrix/screenshots/` 便于查看。

## 对比度与限制

程序核对普通文字／页面、卡片、淡青底至少 4.5:1，白色主按钮文字至少 4.5:1，必要控件边界至少 3:1。标题和导航具备语义节点，帮助关闭后恢复触发入口。节点与焦点断言不能替代 TalkBack 实际操作。

| 项目 | 本轮状态／独立验证口径 |
| --- | --- |
| 实体手机阅读、游戏中打开设置、患者理解 | 待测；模拟器截图不代表患者可读性已通过 |
| TalkBack 实际朗读、探索、焦点顺序和返回 | 待测；本轮只验证无障碍节点和程序焦点 |
| 游戏内真实声音、震动与蓝牙可听性 | 待测；本轮没有更改声音机制，也没有外部声学测量 |
| 温升与识别处理时延 | 待测；同机热点、画质、音频、充电和起始温度一致，各模式至少三次连续 15 分钟对照；P95 恶化超过 10% 或匹配温升增加超过 1°C，增强不进入患者试用 |
| 公网更新下载与系统安装 | 待负责人上传后核对附件与清单，再在手机验证；本轮只生成文件、检查本地摘要与签名 |
| 设计奖项与符合度评分 | 无评审结论；参照作品不构成获奖或分数恢复证据 |

历史评分与 `verified`／`release_ready` 沿用原值。本轮补强设置可理解性、学习入口与大字适配的工程证据；不把 UI 自动化通过等同于目标玩家验证。
