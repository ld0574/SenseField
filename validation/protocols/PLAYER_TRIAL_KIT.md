# 听野玩家陪同试用包

更新于 2026-10-03。本文件和 `validation/` 根目录的 [离线记录表](../player-trial.html) 是空白模板，不含任何患者或玩家数据，也不表示试用已经完成或产品已验证有效。

## 本轮范围

- **优先人群：**自述有管状视野、周边视野缺损的人；能用自己熟悉的方式完成主要游戏操作，并愿意参与。
- **探索人群：**其他类型低视力，只要仍能完成主要操作，就可以参加。探索组的反馈分开记录，不据此推断所有低视力玩家都适用。
- **不支持：**全盲。此轮不邀请全盲参与者；无需记录或解释个人病情。

本轮试用手机需运行 Android 10 及以上；这只是报名条件，不代表所有具体机型已验证兼容。负责人应在试用前核对安装、声音输出与实际提示通道。

公开体验下载版为 0.3.5；另有本地 0.3.6 代码候选，仍待真机验证。两者都仅尝试提示《王者荣耀》小地图上已显示、进入自身附近范围的部分敌方标记；没有覆盖全部游戏画面、文字或菜单，不会代替玩家操作。试用时记录设备上实际运行的版本，不能把本地候选描述成公开版本或已验收版本。提示可能漏报、偏移、迟到或打断游戏，玩家可随时暂停或退出。招募目标 3–5 人只是安排目标，不是配额、统计效能或疗效证据。招募按自愿和功能条件进行，不以某种视力人群的人数构成保证效果。

报名可由负责人在线上或线下安排。此试用包不收姓名、联系方式、诊断名称或证明、游戏账号、住址等身份信息；请勿把这些内容写入自由文本。报名联系：________________（留空，由负责人另行安排）。

## 试用前说明与授权

开始前用参与者能理解的方式说明：这是实验性游戏辅助体验，不是医疗或临床工具；不会诊断或治疗；不承诺能识别全部信息或一定有帮助。参与者可以拒绝回答、要求暂停或退出，不影响其后续参与。先试听当前实际启用的通道，确认参与者能听见或感觉到示例，再开始对照。

试用参与、屏幕/声音录像、诊断日志保存、向团队以外分享记录或引用玩家原话，应分别征得明确同意。拒绝录像或分享不影响参加。未取得同意时不录制或导出相应材料。记录文件保存在本地受控位置，不自动上传；分享前去掉可识别信息。

表单使用随机匿名代号，例如 `P01`；不要用姓名缩写、生日、病历号等生成代号。表单不含身份联系字段。由负责人协调的实际联络信息若确有必要，应由负责人另行处理，不合入试用记录。

## 对照流程

建议每次约 20–30 分钟，过程中由参与者正常玩，记录员负责记录，避免要求玩家边操作边填表。明显不适、疲劳、发热或参与者要求停止时立即结束并记录原因。

先固定手机、游戏音量、输出设备、画质/帧率、游戏模式、充电状态和提示通道。记录提示开关的真实状态：语音、方向提示音、震动分别是开或关，不以计划设置代替实际设置。条件顺序按匿名场次在 **AB / BA** 间轮换；不要所有人都先做同一条件。

对于玩家效用对照，A 为辅助关闭，B 为辅助开启；尽量用相近、可重复的训练场或自定义场景，记下实际任务和事件时间。除辅助开关外保持其他设置一致。游戏胜负不能单独作为产品效果指标。若无法重现相近场景，照实标明差异，不强行比较。

如果需单独定位双手操控问题，再做另一组工程诊断：A 为双手持续操控，B 为双手暂时离开操作区。两种条件不要与辅助开关的 A/B 混为同一对照；记录清楚工程诊断用的条件标签和顺序。此工程诊断的事件数量目标仅适用于该诊断，不是每位参与者的试用要求。新一次近区进入前，应先确认上次占用事件结束且重置条件满足；敌方标记持续在近区时没有重复提示，不算新的独立事件。

每个观察事件尽量保留以下关联：匿名场次、条件、应用日志中的原始 `cue_id`、游戏 HUD 时间、未经剪辑的外部录像时间锚、必要的帧/日志引用、玩家听见/感觉到什么、记录员独立观察到的提示条件。不能用“应用响了”反推它本来就应该提示，也不能把事件回调当作实际发声。

**提示偏移要分清当时和后来。**记录玩家听到提示的时点和随后看见目标的时点；记录员应按提示时点的画面独立核对当时方位。若目标后来移动后看起来方向不同，标成“方向体验待核实”，不要直接判应用方向错，也不要直接判它已正确。0.3.5 已有一条方向回忆与移动中的候选相容、但缺少同刻人工真值的记录；它仍待核实。

## 必记内容

- 玩家本人描述最容易漏看的游戏信息、熟悉的操作方式，以及能否完成主要操作；只记功能需求，不收疾病诊断或证书。
- 实际设备、Android 版本、听野版本、任务与场景；需要测发热时记起始/结束时间、可取得的电池读数、机身主观冷热与是否不适，不把电池温度当作外壳或芯片温度。
- 语音、方向音、震动的真实开关与可感知情况；播放器/系统回调另行记录，且明确它们不证明参与者实际听到或感到。
- 每条提示是否听懂、是否及时、方位是否符合提示时点、是否帮助发现原本漏看的信息、是否打断操作或交流。允许“否”“不确定”及参与者自己的描述。
- 观察者核对的独立应提示事件、实际提示、漏报/无关/误导/待核实；保留没有提示的事件和失败案例。
- 结束时参与者最希望改变的一点、是否愿意继续体验，以及反馈后团队的决定、版本、改动与复测结果。

引述玩家原话、录音、视频、截图或诊断包之前，另行确认准确的使用范围。无法匿名化的材料不进入路演或公开仓库。不得把试用分数或玩家人数转换成疗效声明，也不得声称代表所有低视力者。

## 延迟 CSV：可选的高级记录

需要测量端到端实声时，可在 HTML 的“外部影音延迟（可选）”展开区独立导出 CSV，列为：`event_id,cue_id,kind,evidence_ms,audio_ms,source_note`。此 CSV 与反馈 JSON 分开，空白模板默认没有样本。当前工具接受 `near_zone`、`player_dead`、`player_alive`、`radar_status` 及原有 `main_enemy`、`minimap_enemy`、`danger_ping` 类型；具体选择应与该版本日志的事件类别一致。

`evidence_ms` 与 `audio_ms` 必须从**同一份未经剪辑的外部影音**、相对原始媒体起点以毫秒记录：前者是画面中独立确认提示条件成立的时点，后者是该次声音在录音里实际开始的时点。没有实声或无法确认时，`audio_ms` 留空并在 `source_note` 说明。参与者回忆、手机系统时间、应用回调、`STARTED`/`COMPLETED` 字段和 native 用时都不能填成实际 `audio_ms`。

每个非空CSV行都需填写 `event_id`、`cue_id`、`kind`、`evidence_ms`、`source_note`，只有 `audio_ms` 可留空。表单在下载前检查缺字段、重复ID、非法时间及声音早于画面，发现问题会提示行号并保留未导出状态。匿名事件ID与原始cue ID使用字母数字及 `_.:-`，不含空白；原始cue ID不会被改写。自由文本source_note若看起来像表格公式，CSV以单引号文本前缀导出，测量器仍按文本读取。

逐 cue CSV 是补充证据，不能代替 Android 会话日志、授权录像、人工复核或同一个会话 ID。保留原始文件、时间轴和哈希，另外生成的剪辑只用于展示，不能替代原件。试用 `P95≤500 ms` 是开发试用目标；项目的严格最终验收仍按 `validation/protocols/SESSION_TEMPLATE.md` 和 schema 3 执行，包括实际发声端到端 `P95 ≤250 ms`、实体机横屏会话平均 `≥8 FPS` 和最大帧间隔 `≤2 s`，以及逐类质量和独立留出等要求。公开 Release 状态不代表通过这套最终验收；试用目标不降低该门槛。

## 证据与门槛

- 0.3.5 有一份 vivo 真机日志，约 8 分 23 秒、11 次提示请求均被系统接受；没有同刻独立真值证明这些提示都准确，也没有证明参与者每次实际听到或感觉到。它不足以替代 ≥15 分钟连续完整会话、两类条件各 ≥10 个独立事件，或玩家试用。
- 专门工程复测的计划目标为：≥15 分钟连续会话、双手操控与双手离开操作区各 ≥10 个独立进入事件、错误或无关提示 `<1 次/分钟`，真实发声端到端 `P95 ≤500 ms`。这不是每位玩家或每次体验的必做事件数量。样本少或无法稳定满足时如实报告，不把它称作普遍性能结论或最终验收通过。
- `500 ms` 的**试用延迟目标**与 0.3.5 的 `500 ms` 观察新鲜度都不等同于严格最终验收。项目验收材料要求留出评测、逐类质量、方向正确率、实体 Android 连续运行、平均 `≥8 FPS`、最大处理间隔 `≤2 s`、每种启用提示足量真实发声配对样本，以及真实发声 `P95 ≤250 ms`。例如 `validation/protocols/SESSION_TEMPLATE.md` 的 schema 3 最终证据门禁仍适用；近区试用 CSV 不可绕过它。0.3.5 已公开发布并不等于该门禁通过。
- 每个反馈事项要串起“玩家反馈 → 团队决定 → 对应版本/改动 → 复测证据”。未改、无法复现和方向待核实也要保留，不把待办写成修复完成。

## 表单操作与数据保存

`validation/player-trial.html` 可完全离线打开。样式、脚本都内嵌，不访问外部服务。表单不使用 `localStorage` 或自动上传；刷新、关闭标签页或浏览器崩溃会丢失未导出的数据。开始填写后，离开页面会提醒；完成一轮后使用“下载 JSON”保存在本地，或用“复制文本”保存到受控位置。需要续填时可导入本表导出的 JSON；导入仅载入当前页面，仍须重新下载才会保留。主表 JSON、延迟 CSV 的未导出提醒和导出状态分开计算；复制摘要不会清除任一提醒。延迟 CSV 单独下载。导出前不要关闭或刷新页面。不要把 JSON/CSV 上传到未批准的云服务。

空表、字段含义与建议流程都留在本包；填写时尽量使用本人可访问的字体大小、键盘或读屏操作。若表单难以操作，可由记录员按玩家口述填写并复述确认，不要求参与者自行操作界面。

## 工具验证复现

表单的导入/导出、删除再新增后的label ID、分开保存提醒和非法CSV拒绝用无网络DOM环境验证。它不启动浏览器，也不加载网络资源：

```sh
npm install --ignore-scripts --no-audit --no-fund --prefix build/score-recovery/qa-deps jsdom@26.1.0
NODE_PATH="$PWD/build/score-recovery/qa-deps/node_modules" node --test tests/test_player_trial_dom.cjs
```

7项通过。浏览器自动化尝试打开本地 `file://` 页面时被URL安全策略拒绝，因此本轮没有浏览器视觉、手机布局或真实读屏验收，也未尝试替换协议或浏览器绕过。DOM验证只证明对应交互逻辑；字体、焦点朗读与手机体验留待使用时核对。
