# 验证方式与使用条件

听野包含 Android、Python 和 C++ 的自动回归工具，并结合真机试用检查声音、触觉、视觉高亮及交互。测试结果绑定相应源码、安装包和输入，避免将历史结果沿用到其它制品。

## 功能与使用条件

| 能力 | 使用条件 |
| --- | --- |
| 王者小地图提醒 | 玩家授权屏幕采集；核心识别在手机本地运行 |
| 消消乐交换提示 | 棋盘稳定且信息可确认；动态语音需要可用中文 TTS |
| 语音与画面助手 | 用户开启并分别授权；语音本地识别，画面问答需要网络 |
| 视觉高亮 | 用户授予悬浮显示权限 |
| 更新安装 | 使用匹配包名、签名和校验清单的安装包 |

消消乐已测通 120 关。不同机型、关卡与游戏版本需结合实际使用确认；模型回答也应依据截图事实判断。

## 开发检查

```sh
PYTHONPATH=python python3 -m pytest -q
```

Android 修改按[开发指南](../docs/development/团队协作与本地运行.md)运行 JVM、构建与 lint；消消乐使用[专项回归](../docs/development/match3-regression.md)。发布前核对实际 Release 包、声音、授权、高亮与停止辅助流程。

独立精度、响应时延、玩家收益及温升需要各自的测试条件，单元测试和示意素材不替代这些结果。需要记录时使用[会话模板](protocols/SESSION_TEMPLATE.md)。
