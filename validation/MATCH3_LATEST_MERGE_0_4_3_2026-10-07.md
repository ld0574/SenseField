## 合入内容与冲突处理

- 保持 `0.4.3 / versionCode 20`、原签名、听野公网助手与 Gitee 更新配置。来源分支独立的 `0.4.30 / code27` 不作为本次发包版本。
- 合入冰块与空位分类、不可交换的语义、棋盘边界 v3b、冰块关卡／双箭头／目标栏三条说明；主分支现有棋子模板优先级继续适用。
- 首播或过渡后，要求两个连续稳定窗一致；确认状态属于本次投影，弹窗、点读切换及重新标定后重新确认。常规局面更新保留原去重和播报间隔。
- 活跃投影下重复 START 在拆旧投影前忽略，不重用一次性授权令牌。更新 service start ID，保证系统终止当前投影时能停止最新投递；旧投影的回调不能停止或修改新会话。
- 启动诊断提前到投影创建之前，区分前台服务、令牌、虚拟屏幕和会话初始化失败。系统终止投影记录 `projection_stopped`，沿用主分支文字提示及释放资源流程；不把发起 TTS 后立即销毁服务当作声音已被听见。
- 消消乐语音通道异常不会中断录屏处理；记录投递、接受／拒绝、真实播放器回调与错误分类。回调审计避免反向获取投影锁。消消乐去重至少 1.5 秒，继续尊重已有静音、系统提示及语音设置；王者音频链路不改。
- 诊断 metadata 增加来源分支使用的 `app_version`，并保留已有 `version_name/version_code`；均对应实际 APK 的 0.4.3／20。
- 保留主分支的逐会话状态、旧帧保护、录屏互斥、Bitmap 回收、每 800ms 最多一次转换、异步 RGBA 诊断与本地棋盘链路。分支进度自动合并到 `research/board-recognition/TEAMMATE_PROGRESS.md`。
- 首页仍为左右游戏卡片，两款入口使用「开始辅助」，消消乐副标题为「休闲益智辅助」；助手继续默认关闭。
