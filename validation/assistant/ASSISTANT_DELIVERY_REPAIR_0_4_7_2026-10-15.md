# 0.4.7 播报与模型输出修复

2026-10-15，依据[本局分析](ASSISTANT_OPEN_CONVERSATION_LIVE_0_4_7_2026-10-15.md)修正已证实的问题。用户明确选择继续由听野覆盖 TTS 语速，本轮未调整语速来源、保存数值或范围。

## 行为变化

- 纯提示音和振动不再取消助手回答。附近敌人、边缘威胁或危险语音预警需要声道时，先让本地预警播报，再续播助手尚未完成的句段。被打断的句段从头播，完整播完的句段不重复；不发起额外云请求。
- 正在合成或排队的回答也保留。续播复用原创建时间、绝对过期时间及调用方归属检查；新问题、用户暂停、撤权、关闭或原信息过期后不续播。语音队列仍最多八条，本地语音优先于助手，即使其数值优先级较低。
- 诊断新增 `YIELDED`、`RESUMED`、`PARTIAL_EXPIRED`、`PARTIAL_LIMIT` 等状态。已播放前段、后段过期时不再返回成功；句段预算省略内容也不能记为完整完成。续播时保留尚未完成的原文，不截掉否定、条件或未完成的尾部。
- 服务端仅提取并验证所需字段，忽略额外元数据；未知的可选场景提示会移除，不获得额外时效。模型额外输出 `answer_scope` 不能改变手机请求归属或时效，回归继续验证这一点。
- 不再因正文超过一百字或两句话而整段作废，不强行裁剪正文。保留四百 UTF-16 单位的手机传输上限、必需字段、类型和不确定性检查；超预算、非法 Unicode 或真正的非 JSON 输出仍拒绝。结构错误记录固定的 `validation_issue` 分类，不记录原话或模型正文。
- 中文提示词继续以“正在为低视力用户服务的游戏搭子”为身份，首句先给短结论，通常二十至四十个汉字，必要时补关键依据和条件。没有重新加入问法或输入字数白名单，没有更换模型或增加手机 OCR。

## 保留的证据边界

旧局中两次模型不确定不被强制改为确定；那次 `invalid_output` 没有原始正文，无法宣称已逐字复现其具体格式。输出协议回归只证明已覆盖的类型可正确处理，不是模型事实准确率或策略收益声明。

五段一至二字 ASR 结果的真实含义、端点是否切碎及追问上下文缺口，缺少原话与原音证据。本轮没有用关键词或字数过滤掩盖这些问题，没有将其登记为已修复。独立准确率、自然 ASR、整局实声、受控温升与整体成本仍保留原验收边界；私有诊断、截图、音频、Key 与 `demo-video/` 素材不进入交付或公开仓库。
