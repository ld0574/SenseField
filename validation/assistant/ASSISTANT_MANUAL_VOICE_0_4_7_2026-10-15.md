# 0.4.7 外放单次语音提问（2026-10-15）

第二台手机的原始诊断表明，外放路由被连续语音的耳机检查暂停，未进入 ASR。本轮增加有明确起止的“说话／说完”入口，保持耳机连续语音与原有麦克风检查。手机修订无需更新 Python。

## 行为及边界

- 外放时点“说话”开始一句提问，说完自动提交，也可点“说完”。五秒无声退出，单次最长十五秒。旧计时器与旧结束回调不能关闭新一轮。
- 单次入口允许扬声器路由，不能绕过用户暂停、系统静音、其他麦克风录音或权限撤销。设备声音内录的 `REMOTE_SUBMIX` 与麦克风录音占用分别诊断。
- 开始与结束时清除旧音频缓冲，避免把点击前的平台缓冲接到新问题。暂停期间不会因点击重新启动录音。
- 外放窗口外不送入语音识别；这不表示底层麦克风循环物理关闭。耳机下原连续输入继续生效。
- 游戏人声仍可能混入。没有恢复问法白名单；每句非空识别文字仍按原话提交。
- 面板有无障碍点击与明确的“说完”标签；收起再展开不丢失结束入口。日志增加单次窗口起止、输入模式与真实本地 ASR 就绪事件，不保存识别原文。

Release 中的监听接口经过 R8 优化后，直接创建这些内部类型的独立测试 APK 无法加载它们，控制器测试也因此初始化失败。支持跨 APK 调用的设置、VAD 和离线 ASR 单独运行 7 项通过；此结果不证明 Release 面板与手动输入已经完成原生验收。完整 Release 控制套件与真机外放语音仍有验证缺口，本地候选按工程部分验证登记。测试辅助包初次重建缺少签名的安装失败已保留；最终辅助包与主包使用同证书签名。

合成语音只验证离线模型、协议与关键词通路，不代表真人 ASR 准确率、外放回声表现、游戏人声抗干扰或真机速度。早期模型缓存不完整与高负载初始化超时的失败日志继续保留。本轮没有在真机覆盖安装主 APK，也没有要求用户重开游戏。

原始工程日志与截图仅在忽略目录 `validation/private/assistant-manual-voice-20261015/`。最终本地候选的工程回执位于 `output/releases/0.4.7/validation/current-package/`；本轮不自动发布或更新公网清单。
