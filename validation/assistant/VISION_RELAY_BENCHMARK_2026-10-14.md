# 新中转站视觉速度实测

2026-10-14，最初实际请求 `https://www.tokens1688.com/v1/chat/completions`，合成图对照建议先使用 **Kimi-K3**：它在短提示词对照中完整回答中位最快，在当时的听野客户端、旧系统提示词和8秒预算下三次均正确，完整回答中位2.27秒。该历史选型不能代表后来中文提示词及真实游戏画面的速度。

后续[真实游戏截图22次对照](REAL_GAME_VISION_LATENCY_0_4_7_2026-10-14.md)发现K3选人有超时和身份错误，K2.6偏慢；GLM Flash战绩页约2.7秒，但五次选人格式均失败，MiniMax探测也未得到可用提速。当前没有通过5秒选人要求的替代路由，不再凭原合成图成绩声明K3已经满足选人体验。

## 同图同提示词对照

四款截图中标注视觉的模型各请求三次，使用三张 960×540 合成 JPEG，每轮所有模型读取同一张图。图片明确提供随机代码、血量、红点数量及相对蓝点的方向，检查实际读图和 JSON 结果；请求串行、轮换顺序，`stream=true`、`max_tokens=256`、`temperature=0`。没有上传诊断中的游戏画面。密钥仅用于请求进程，未写入配置、日志或仓库。

| 模型 | 读图正确 | 首个回答内容中位 | 完整回答中位 | 完整回答范围 |
| --- | ---: | ---: | ---: | ---: |
| Kimi-K3 | 3/3 | 1.97 秒 | **2.40 秒** | 2.00～9.78 秒 |
| Kimi-K2.6 | 3/3 | 2.22 秒 | 2.66 秒 | 2.49～2.80 秒 |
| glm-5.3-flash | 3/3 | 3.71 秒 | 4.03 秒 | 2.78～18.39 秒 |
| glm-5.3 | 0/3 | 无回答 | 无回答 | 三次 HTTP 400 |

`glm-5.3` 当前路由拒绝 `image_url`，错误说明只接受 `text`；截图的视觉标签不能证明本次接口能收图。首字仅统计 `content`，思考内容不计入。首次 Flash 的等待尖峰保留，没有以预热为由删除。

## 关闭思考的附加探测

另发 `thinking={"type":"disabled"}`，成功模型各三次，拒绝参数后停止该模型后续探测，共八次请求。

| 模型 | 结果 |
| --- | --- |
| Kimi-K3 | 3/3 正确，完整回答中位 2.12 秒，范围 2.11～4.57 秒；这三次没有返回思考内容 |
| glm-5.3-flash | 3/3 正确，中位 2.48 秒，范围 1.55～2.87 秒；两次仍返回思考内容，不能称为稳定关闭思考 |
| Kimi-K2.6 | HTTP 400 `InvalidParameter`；继续使用现有默认请求 |
| glm-5.3 | 仍拒绝图片输入 |

本组样本不能证明延迟变化完全由该参数造成；缓存、时间和中转路由均可能影响结果。现有兼容客户端不会为上述模型自动发送该扩展字段，本轮没有据此修改生产请求。

## 听野现有生产客户端复验

再使用实际 `CompatibleVisionClient`、仓库中的完整 `SYSTEM_PROMPT`、原 `max_tokens=256` 与 8 秒超时，对两个 Kimi 模型各请求三次。输出交给现有 `parse_visual_answer` 检查；K2.6 一次带 JSON 代码围栏，现有解析器正确接受，未误记为服务失败。

| 模型 | 网关解析后读图正确 | 首个回答内容中位 | 完整回答中位 | 范围 |
| --- | ---: | ---: | ---: | ---: |
| Kimi-K3 | 3/3 | **2.05 秒** | **2.27 秒** | 1.90～3.27 秒 |
| Kimi-K2.6 | 3/3 | 3.62 秒 | 4.09 秒 | 2.31～6.34 秒 |

选型阶段共 26 次真实请求，使用当时的短测试提示词或旧生产提示词。完整回答是当前网关等待的结果，不能用思考开始或首个 JSON 字符当作手机已经获得可播报建议。每条件三次只支持本次选型，没有足够样本计算可靠 P95、高并发稳定性或真实游戏理解准确率。K3 默认对照中仍有一次 9.78 秒尖峰，不能承诺团战 1～2 秒内返回。

用户随后要求中文游戏搭子身份，并聚焦选人和后续出装。新的可编辑提示词另以六次实际请求探测：显式关闭思考后，两张合成决策图回答约 5.23／7.16 秒，两个即时团战探测均超时；默认请求中的格式失败也保留。新网关对明确的即时团战问题直接转向本地预警。详见[后续修订与验证](../honor/HERO_FEEDBACK_2026-10-14.md)，不将旧提示词的速度移植到新提示词。

接入配置为 `ASSISTANT_GATEWAY_VISION_PROVIDER=compatible`、`ASSISTANT_GATEWAY_VISION_BASE_URL=https://www.tokens1688.com/v1`、`ASSISTANT_GATEWAY_VISION_MODEL=Kimi-K3`；密钥填在服务器私有配置。客户端会自动添加 `/chat/completions`。部署者更新配置后重启并运行 `deploy/assistant/verify.py --config ... --visual`，实际网关读图成功后才能记录服务恢复。团战接近预警继续由手机本地轨迹处理。
