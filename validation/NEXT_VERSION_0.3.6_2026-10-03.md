# 0.3.6 评审补强交付记录

日期：2026-10-03。基线：已公开的0.3.5。当前源码 `versionName=0.3.6`、`versionCode=14`；公开下载仍是0.3.5，本轮候选留在本地。目标、历史需求对照与后续验收见[Goal](SCORE_RECOVERY_GOAL_2026-10-03.md)。

## 修改与目的

1. 诊断缩略图复制：优化逐像素读取路径，保留原crop、nearest-neighbor采样、颜色、尺寸和窗口策略；减少诊断同步开销。具体方案与测试见[优化记录](DIAGNOSTIC_COPY_OPTIMIZATION.md)。没有同机数据，不能称为已降温。
2. 开始前左右短音试听：沿用实际近区短音与左右声道增益，先说明左侧再播放，再说明右侧并播放。提示单声道、耳机佩戴和外放辨位限制；关闭近区短音时不加入示例。短音仍只能区分左右，语音提供8向，手机震动不编码左右。此改动不在游戏内新增播报。
3. 离线诊断报告：按cue ID/事件时间关联dispatch、回调、窗口、保存截图和运行负载；提供原档案哈希和证据缺口。真实报告只存ignored output，公开仓库仅放工具和虚构测试fixture。
4. 实声测量补齐近区类别：旧测量器只接受三类检测事件，无法录入当前 `near_zone`。现在接受Android实际输出类别，保留缺失声音、重复cue ID及非法时刻的拒绝规则；不更改旧质量评估器与最终门槛。
5. 匿名试用记录：离线表单支持辅助开关对照、真实通道设置、理解/感知、帮助与干扰、热量和逐项反馈决定/复测。导出JSON和独立实声CSV，不自动上传，不把播放器回调填成实声时间。
6. 证据口径：补v6 512模型现状，区分历史320、开发指标、真机数据、试用目标和严格最终门槛。逐项记录评估缺口，不重新估算或承诺得分。

模型、profile、native识别、近区范围、提示频率、500 ms观测预算、热档策略与0.3.5相同。疑似方向偏移未取得同一时刻真值，继续待核实；本轮不训练、不扫阈值、不打开封存video9/video12。

## 可复核演示

演示分为工具与真实使用两部分，来源写在画面或说明旁。

1. 安装候选，打开提醒说明，展示左右短音、语音、震动开关与试听。现场必须由玩家或观察者确认实际听见/感到，模拟器和回调仅证明流程。再展示授权、通知暂停/停止/标记问题和诊断导出。
2. 将经授权的真实诊断ZIP放在本地，运行[报告命令](DIAGNOSTIC_REPORT.md)，从cue进入相关当帧和上下文，展示有证据/缺证据的区别。原始截图不要直接用于公开路演。
3. 用[空白试用表](player-trial.html)演示一次虚构记录和导出，明确标“模板演示”；真实试用后替换为获得使用授权的匿名记录。展示一条反馈到改动到复测的关系，不用游戏胜负代替帮助程度。
4. 按需运行 `mapassist.measure_latency` 汇总外部原录像实声CSV。未配对的声音继续记missing；近区测量报告不代替严格最终门禁。

公开视频或路演只能使用已获对应分享授权且不能识别参与者的素材。没有真实患者材料时，保留空模板及待办，不制作假反馈。
