- 录屏保留 main 的旧会话隔离、旧投影回调防护、与王者录屏互斥和启动失败清理。控制命令更新服务 start ID，但不替换投影；旧帧不能持久化标定或提交播报。定时任务也绑定投影会话，切换会话或点读模式时清除旧播报。
- 每个投影持有独立识别状态和一个截图。每次 ImageReader 回调都取走并关闭图像，整屏 Bitmap 转换每800ms最多一次；替换与结束时回收 Bitmap。模板匹配中的临时裁剪和缩放图也及时回收。
- 游戏内点读使用正在处理的实际截图，先初始化采样器再处理点读；忽略过期触摸及棋盘外点击。启用须 Android14+和无障碍服务；系统 motion event sources 设置先于 setServiceInfo，服务销毁清空旧触摸/读屏缓存。
- 空闲提示不在点读、弹窗、坏棋盘或过期帧期间播报。重新标定后重新积累三帧，避免拿单帧修复结果直接播报。现有识别阈值未调整。
- 修正弹窗平均亮度的浮点累加；此前 long 的复合赋值会逐像素截断小数。
- 消消乐诊断采用合法 UUID 会话名，复用原始 RGBA、异步编码与原有截图预算。仅消消乐显式允许竖屏图片，王者仍保留横屏限制。记录采样状态、棋盘信息及播报请求；通知保留“标记问题”和“停止”。
- 实时棋盘链路保持本地处理，不调用新增 CloudVision 实验实现，不阻塞录屏线程或自动切换付费提供方。实验性 Jev 控件仅在显式启用对应配置后显示。
