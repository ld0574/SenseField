# 消消乐主动审查与自动回归：0.4.5

本记录保留自主审查批次当时的测试与制品摘要；后续入口、设置与局部排序修订已覆盖同版本，当前唯一交付见[设置与局部排序记录](MATCH3_VALUE_AND_SETTINGS_0_4_5_2026-10-09.md)。

本批继续覆盖 0.4.5／code22，以[真机反馈修订](MATCH3_0_4_5_REAL_DEVICE_FIX_2026-10-09.md)为基础。目标是先由开发者检查识别、推荐、播报、高亮和资源生命周期，将可自动发现的错误挡在玩家试用之前。未改王者模型／参数、已有音色、助手默认关闭或生产服务。

## 复现与整改

第一组 6 个用例在修复前全部失败，另有 2 个模板语义用例在修复前全部失败。原始输出分别保存在 `validation/private/match3-audit-before.txt` 和 `match3-template-semantics-before.txt`，没有用改写通过结果代替失败记录。

| 问题 | 复现依据与最终行为 |
| --- | --- |
| 空洞／冰块被计作识别失败 | 可读的稀疏棋盘因非动物超过 40% 被拒绝。区分未知、已知非动物和可移动动物；40% 未知门槛保留，已知空位／冰块不消耗未知预算。 |
| 单帧旧画面恢复推荐 | 已接受 A 后，B 和返回的单帧 A 都被旧确认器放行。每个原始采样都进入确认器，任何变化都先撤下旧推荐；返回的 A 也要连续确认。 |
| 无效矩阵／选区导致崩溃 | 空、null、不完整矩阵，以及负坐标选区可直接抛异常。无效棋盘不产生建议，选区夹到棋盘范围内；错误样本中断确认序列。 |
| 未知字符生成假三连 | 旧逻辑将未列出的字符也当成动物。匹配只使用明确的普通动物字母。 |
| 自定义外观标签被当成游戏规则 | 木箱／炸弹等标签被分配数字／小写字母，旧逻辑按同字符三连推荐。外观标签保留识别与点读，不据此推断颜色、可交换性或特殊组合。 |
| 名称里的颜色词改变分类 | “红色木箱”“蓝色冰块”等被子串规则映射为普通动物。改为六种基础动物的明确别名；识别 HSV、模板距离和颜色阈值未变。 |
| 别的学习库改掉当前名称 | 静态编码表每次加载重排，现有采样器会读取新表。模板编码和点读名称归属于各自加载的目录快照，另一个目录加载不改变当前采样器。 |
| 消除期间继续推荐 | 已出现三连的画面尚未完成消除。自动提示等待其消除后重新确认局面，不朗读“等待稳定”等状态。 |
| 模板资源没有明确释放 | 失败候选、几何撤销、截图点读及模板保存中的位图现在有明确的持有和释放边界；重复关闭安全，不回收调用方的截图。 |
| 每格重复缩放所有模板 | 相同 16×16 比较数据改为加载时缓存；每格只读一次比较像素。原生缩放与距离结果逐像素相同；弹窗检测复用 HSV 数组。未据此宣称温降。 |

交换逻辑还使用独立的“三格窗口”规则核对 512 组 6～9 行列棋盘及其镜像／转置，验证推荐集合、相邻端点、障碍不能参与、排序和原矩阵不变。独立校验器没有调用产品的三连／交换判断来生成答案。历史诊断 JPEG 是故障回归输入，不是独立准确率样本。

## 独立待验证部分

真实手机游戏的边框对齐与持续可用、MultiTTS 外部录音中的读音／完整性、患者找格体验、Android10／13 的系统行为，以及条件匹配的高亮开关各 3×15 分钟温升仍待验证。识别处理 P95 恶化超过 10% 或温升增量超过 1°C 不记患者试用通过。自定义特殊棋子的玩法、颜色和移动规则不能通过外观命名推断，未宣称支持其自动推荐。

工程测试不替代独立准确率、500ms 实声或 250ms／8FPS 严格门禁。未训练、扫描阈值或读取封存视频；历史评分、`verified`、`release_ready` 未改。今后先通过自动门禁再交付，只把真实听感、可用性和受控温升留给玩家与独立测量。
