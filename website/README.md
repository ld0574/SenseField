# 听野 SenseField 官网

官网：<https://ld0574.github.io/SenseField/>

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
cd website
npm ci
npm run dev
```

本地地址：<http://127.0.0.1:5173/SenseField/>。

```sh
npm run verify
npm test
npm run build
npm run preview
```

`verify` 检查品牌色、中文默认文案、双语入口、锚点、Lucide 图标、展开式功能、折叠式 FAQ、消消乐验证文案和动态下载；`build` 先执行 TypeScript 检查，再输出 `dist/`。测试覆盖中英反馈校验和动态发行信息的解析、下载链接校验及请求失败。

## 自动部署

`.github/workflows/website.yml` 在 `main` 的官网文件更新后构建并部署 GitHub Pages；Pull Request 只检查与构建，不部署。GitHub 仓库 Pages 的 Source 应为 **GitHub Actions**。也可在 Actions 手动运行 **SenseField website**。发布 APK 或修改版本清单不需要重新构建、提交或部署官网。

项目子路径在 `vite.config.ts` 中固定为 `/SenseField/`。更改仓库名或绑定独立域名时，应同步修改此路径与 `index.html` 中的 canonical、Open Graph、结构化数据及 `public/sitemap.xml`。

## 维护与品牌

- 官网沿用 Android `UiKit.java` 的既有色值：暖白 `#FBF7F1`、青蓝 `#236874`、深色 `#193139`、淡青 `#E7F2F2` 与杏色 `#F0C6B2`。
- 原有听野标志与品牌配色没有重设计，所有界面图标统一使用 Lucide。
- 中文是默认语言，页首提供英文切换，文案、控件、无障碍标签和反馈校验一起切换，保留表单填写内容。语言偏好在本地保存，也支持 `?lang=en` / `?lang=zh` 指定语言。版本更新说明沿用 CDN 的中文原文，英文界面注明语言。
- 唯一版本来源为 <https://888413.xyz/apk/latest.json>。首屏与下载区域的 APK 地址、版本、包大小、更新说明和结构化数据统一由 JSON 赋值，不在 HTML 中固定发版地址。
- 页面每次进入都直接请求 CDN 原始清单，不再保存或部署站内 `latest.json`，也不依赖 Actions 定时同步。请求使用 `cache: no-store`、时间戳查询参数和 `credentials: omit`。打开着的页面每 5 分钟重新读取；切回标签页或从浏览器历史恢复页面时也会重新读取。即使版本号没变，包大小、校验值与更新说明也全部以当次 JSON 为准。
- 云 CDN / 对象存储需为 `/apk/latest.json` 允许跨域读取，配置方式见 [CDN.md](CDN.md)。首次设置后刷新该文件的 CDN 缓存；建议关闭这个小文件的边缘缓存，避免查询参数被 CDN 忽略时仍返回旧内容。
- 版本清单读取失败时显示无法读取的提示，两处下载按钮都回到可访问的码云发行页。页面会清除上次的版本、更新说明与结构化下载数据，不用旧清单冒充最新版本。
- 首屏感知透镜由 Three.js 本地生成，中心复用原有听野标志；连续折射光环、扫描弧线与方位标签呈现感知概念，不使用粒子，不下载模型。WebGL 不可用时显示带原标志的 CSS 静态透镜。平滑呼吸与阻尼指针响应自动播放，不需要点击触发；移出视口、隐藏页面或暂停动效时停止动画帧。
- 首屏保留环形声波、杏色扫描弧线与扩散脉冲，四项醒目的 Lucide 标签突出声音、语音、触觉、视觉；视觉说明为「高亮细节」，不局限于交换位置。手机布局将四项标签放在下载区之后、艺术视觉之前，便于首屏阅读。移除透镜内的两个方块和首屏顶栏文案；首屏底栏随内容排布，版本信息与横线保留间距。页头和页脚的听野标志副标题统一为「无障碍游戏辅助」。色彩仍来自既有品牌色。「为什么做听野」将标题与安卓手游图片并排，下方按两列解释设计原则与玩家处境；功能标题右侧显示当前支持的三项功能概览。
- 声音演示在用户点击开启后才播放；页面隐藏或离开演示区域时停止。八个方向分别演示敌人、兵线、开团、草丛动向、队友集合、绕行、支援与防御塔受攻击的不同情境；中英文字与语音共用同一份内容。这些情境仅为概念演示，不代表实际识别能力。
- 首屏提供 3 分钟实机演示入口，`#demo` 内使用原生视频播放器，从魔搭创空间的公开静态资源地址加载已确认的 v5 成片。保留 1080p、30fps、AAC 立体声和内嵌中文字幕，不自动播放、不默认静音；封面取自成片 2.2 秒。播放实机视频时停止声音概念演示，开启概念演示时暂停实机视频，避免声音重叠。媒体来源及校验值见 [视频分发记录](../docs/demo/video-distribution.md)。
- 功能说明与三项视觉示意全部展开，直接向下阅读；常见问题使用原生 `details` / `summary` 默认折叠，支持键盘展开与收起。使用说明书链接出现在首屏、下载指南、常见问题及页脚；页脚保留听野与罕见病开源社区标志，提供 GitHub、Gitee 链接。
- 消消乐文案按团队反馈更新为已测通 120 关，仅在该功能介绍处出现一次；网页和当前 Android 界面不再使用体验版标记。历史版本记录保留原有说明，智能助手仍为可选实验功能。
- 用户心声支持使用体验、游戏适配和新想法。表单仅整理反馈，用户在 GitHub Issues 检查并发布，需要 GitHub 登录；也可复制整理后的内容。没有伪造用户评价，没有自动提交或隐形上传。无 JavaScript 时仍可将游戏名与正文带到 GitHub。
- 每次进入页面默认自动播放动效，不依据系统减少动态效果设置切换为静态；手动暂停仅作用于当前页面，不会在下次进入时自动恢复。仍支持键盘导航与静态内容阅读；页面不采集用户资料，不使用分析追踪。
- 若关闭 JavaScript，主要介绍、FAQ、文档与下载仍可访问。

素材来源、图片提示词和许可见 [ASSETS.md](ASSETS.md)。安卓手游照片由 `gpt-image-2.5` 生成；素材记录保留生成信息，功能插图均为概念示意。
