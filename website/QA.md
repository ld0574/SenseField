# 官网交付检查

日期：2026-10-13。检查对象：本目录源代码及 Vite 生产构建，浏览器为 Codex 内置 Chromium。

- 品牌：沿用原应用的暖白、青蓝、深色与杏色，复用既有听野与罕见病开源社区标志。
- 静态内容检查：无表情符号，超链接使用 Lucide 水平箭头，所有图标均成功替换为 Lucide SVG；内部锚点和公开素材存在。
- 浏览器：中英两种语言在 320、390、760、1024、1440 像素宽度均无横向溢出；两种语言的手机首屏均能看到下载按钮。主要正文为桌面 18px / 手机 17px，表单输入同步放大。
- 双语：中文默认；195 项以上静态文字与无障碍标签、占位文字、动态版本和声音状态正常切换；选择英文后重新载入仍保留偏好，切换语言不丢失已填写反馈。
- 首屏：连续立体声浪正常显示，已移除粒子、散点及点击扩散入口；暂停前后两张声浪截图像素完全一致；重新载入仍保留暂停偏好。
- 感知体验：未开启声音时保持静音，声音可开启和关闭；左前方提示在中英文之间正常切换，切换时停止先前语音并保留所选方位。
- 功能：三类正文与视觉示意全部展开，不存在隐藏的功能段落，也不需要点击切换。
- 手机导航：展开、点击跳转与关闭有效；菜单图标替换时不会触发错误的外部点击关闭。
- 常见问题：五项问题与回答直接展开，隐私、用户范围与实验边界说明可读。
- 反馈：游戏适配类型将游戏名称设为必填；空表单不会跳转，焦点定位到缺失项；空白文本在英文界面显示英文校验提示。六项反馈测试覆盖中文与特殊字符、必填、空白、长度、最少传输及英文草稿；没有发布测试 Issue。

- 构建：TypeScript、生产构建、公开仓库扫描通过；生产依赖审计未发现漏洞。
