# 官网交付检查

用于官网源码与构建交付的复核。网站构建方法见 [README](README.md)，跨域与缓存规则见 [CDN 配置](CDN.md)。

- 品牌、图片和第三方素材来源一致，资源可读，授权信息完整。
- 中文默认，中英切换覆盖正文、控件、无障碍标签和动态版本信息。
- 320～1440 像素宽度及常见桌面高度下检查排版、导航、下载入口与文字溢出。
- 菜单、FAQ、跳过导航、键盘焦点与页面动效控制能正常操作。
- 声音演示由用户主动开启，关闭及语言切换时停止相应播放。
- 功能描述与实际 APK 对应；概念声音交互与真实游戏识别效果分别说明。
- 下载从固定清单读取版本、说明和 APK 地址；无法读取时显示状态并提供发行页入口。
- 反馈校验覆盖必填、语言、长度和特殊字符，跳转 GitHub Issues 后由用户确认提交。
- 运行项目已有测试、TypeScript 检查与生产构建，核对构建输出的资源和链接。

此清单是检查方法。每次发布的实际结果与截图留在本地，官网检查不替代 Android 真机或玩家验证。
