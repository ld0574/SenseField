# 听野 · 游戏无障碍 Skill

[sensefield-game-buddy](sensefield-game-buddy/SKILL.md) 将听野的画面问答、游戏规则与无障碍表达整理为可复用技能。面向低视力和视野狭窄玩家，默认使用简体中文，先给关键信息或一个有依据的选择，定位使用方向和棋子名称。

重点覆盖《王者荣耀》和《开心消消乐》。其他游戏依据可靠规则和用户输入处理；不承诺未知游戏适配或实时反应能力。

## 立即体验

把技能文件夹导入支持 `SKILL.md` 的智能体。在 Codex 等支持按目录安装的宿主中，将 `sensefield-game-buddy/` 放入宿主的技能目录；宿主的具体安装位置与导入方式以其说明为准。

激活技能后发一张游戏截图，例如：

- “只剩右边一个冰面了，下一步怎么办？”
- “我通常打辅助，这把选谁？”
- “分析一下局势，先说最重要的一点。”

也可以直接打开随包的[合成演示](sensefield-game-buddy/references/examples.md)，无需连接手机或配置 Key。截图读图依赖当前宿主的图像能力；语音播放依赖宿主支持，没有音频工具时输出可朗读文字。

## 包含什么

中文技能入口、王者和消消乐判断规则、App 配合使用说明、合成演示，以及将**已确认合法动作**转成方位口令和静态大框箭头的可选 Python 工具。格式化工具不识图，也不判断动作合法性或最优性。

本包不包含 APK、私有模型、训练图、玩家录像、诊断和接口凭据。手机上的实时识别、声振提醒和悬浮高亮仍使用[听野 App](https://github.com/ld0574/SenseField/releases/latest)。

## 验证与打包

从仓库根目录运行：

```sh
python3 -m pytest tests/test_sensefield_skill.py -q
python3 scripts/package_sensefield_skill.py
```

输出在 `output/skills/`，ZIP 仅包含明确列出的公开文件，附带每个文件的 SHA-256。打包器检查比赛的 30 文件、40 MB 限制。已有同名输出时保留制品并停止，改用新输出路径后再确定交付文件。

演示图由 `scripts/create_sensefield_skill_demo.py` 生成，使用 Pillow 和 macOS 系统中文字体，仅生成时需要这些依赖；使用 Skill 不需要。图中局面为原创合成示意，不能当作真实玩家测试或模型准确率证据。
