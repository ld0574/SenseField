# 无需开游戏的演示

以下图片是随包原创的**合成机制示意**，不是游戏实机截图，不代表识别准确率或玩家测试结论。宿主支持读图时，打开对应本地 PNG 后回答；不能读图时可以使用下面明确标注的文字场景。

## 一、消消乐：把魔力鸟用在最后一个目标上

图片：[assets/demo-match3.png](../assets/demo-match3.png)

用户：“只剩右下那块冰面，下一步怎么办？”

文字场景：6×6 棋盘，右下角是一层静止冰面，上面有蓝河马，可以消除。附近的魔力鸟与其右侧蓝河马可相邻交换；其他地方也有普通消除机会，不能影响最后的目标。静止冰面不同于包裹冻结动物。

合理回答：“右下方，魔力鸟向右与河马交换。右下冰面上的河马也会被清除。”

评审点：先解释目标相关性，而非选择无关区域；不能把换鸟的区域说成目标格；不让用户数行列，不猜后续补子。

可选操作卡：在技能目录运行 `python3 scripts/format_cue.py --input assets/demo-match3-cue.json --svg cue.svg`。生成的是这个合成局面的静态指引，不是往手机屏幕画框，也不执行交换。

## 二、王者：能选的英雄与真正缺的位置

图片：[assets/demo-draft.png](../assets/demo-draft.png)

用户：“我常打辅助，这把选谁？”

文字场景：队友已锁定对抗路、打野、中路、发育路；可选列表中张飞标为游走且可用，蒙犽标为发育路且可用，夏侯惇标为对抗路且已禁用。

合理回答：“优先选张飞补游走位，队友其他四个位置已锁定。”

评审点：结合用户偏好与已锁定阵容，不重复射手，不推荐已禁用英雄，不套固定强度榜。

## 三、信息不足与开放提问

- “这张图野区安全吗？”图中没有可辨敌方标记：只能说当前截图没看到明确标记，视野外和草丛内无法确认，不回答“安全”。
- “升级二技能还是三技能？”角色未给出且图标模糊：说明需要确认英雄或技能含义，不拒绝所有技能问题，也不猜编号用途。
- “继续蹲点吗？”只有一张草丛截图：不能由站位推出蹲点收益，说明要结合目标、兵线和可见敌方信息。
- “右边那个是什么新东西？”只看清新元素外观：描述能看到的形状和位置，依据教程或用户说明核实，不套用另一种元素机制。
- 用户只发“。”或环境噪声转写：不把无有效内容的输入扩写成战术，不主动编一段回复；必要时简短请其重说问题。
