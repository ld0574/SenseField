# 与听野 App 配合使用

Skill 负责根据用户提供的信息进行对话和截图理解；App 才能在用户授权后持续采集手机画面，运行本地识别、声音、振动和游戏内高亮。不要把两种形态的能力混为一谈。

- [听野官网、演示与反馈](https://ld0574.github.io/SenseField/)
- [当前公开版本与 APK](https://github.com/ld0574/SenseField/releases/latest)
- [源码与安装说明](https://github.com/ld0574/SenseField)

用户想实时使用时，指导其安装官方发布的 Android 包，选择对应游戏，试听提示并按 App 流程授权屏幕采集。需要交换高亮时按需授予悬浮显示权限。开始辅助、结束辅助和实际游戏操作均由用户决定。

App 的本地识别核心不依赖大模型问答，游戏资源首次按需下载后校验并离线复用。App 中额外开启的画面助手通过线上服务处理截图；语音识别与所选 TTS 的条件以 App 当前说明为准。Skill 的处理方式则取决于当前宿主，不继承 App 的隐私和离线承诺。

本包没有 APK、模型权重、训练图、诊断、服务地址凭据或 API Key，不需要用户购买听野专用接口。不自动下载模型、不读取手机日志、不模拟触控。用户主动要求联调或反馈时再安排对应工作，不将私人画面和记录用于公开展示。

听野为独立开发的非官方工具，与两款游戏的发行方无隶属、合作或认可关系。公开 Skill 文本和脚本按 Apache-2.0 授权；游戏商标和内容仍归各自权利人，未公开模型与模板的许可不因发布本 Skill 而改变。
