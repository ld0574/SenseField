# 合法动作转成方位口令与静态操作卡

只在动作已由可靠局面分析或可信工具确认后使用。脚本不识图、不搜索最优走法，也不验证冻结、特效、目标收益等游戏规则。`confirmed_legal` 必须反映外部已有依据，不能为跑通命令而填真。

使用 Python 3.10 及以上，无第三方依赖。在技能目录执行：

```sh
python3 scripts/format_cue.py --input assets/demo-match3-cue.json
python3 scripts/format_cue.py --input assets/demo-match3-cue.json --svg cue.svg
```

标准输出是 JSON，其中 `speech` 可直接朗读；可选 SVG 是不会自动消失的指引图。SVG 中的圆点代表内部格子，粗框是动作范围，黄色箭头从棋盘中心指向动作位置。它是单独的棋盘示意，不是实际游戏截图或手机悬浮层。显示给用户前明确这一点。

输入格式：

```json
{
  "rows": 6,
  "cols": 6,
  "action": "swap",
  "source": [4, 3],
  "target": [4, 4],
  "source_name": "魔力鸟",
  "target_name": "河马",
  "confirmed_legal": true,
  "evidence": "合成示例：两颗无覆盖、可移动且相邻，魔力鸟可以与普通动物交换"
}
```

坐标仅供工具使用，为零起始的 `[行, 列]`；不在面向玩家的回答中朗读这些坐标。`swap` 只接受上下左右相邻格；`activate` 的起止格必须相同，且须有可点击激活的游戏证据，不能仅凭特效身份填入。

`rows`、`cols` 范围 1～16；名称为 1～24 字符，依据为 1～240 字符。没有合法性依据、坐标越界、斜向交换、非整型坐标会返回失败，不生成提示或覆盖已有操作卡。名称仅用于展示，不能改变脚本执行。

方位沿用 App 的 `Match3HintGuide`：将动作两格中心的中点落入棋盘的九个三等分区域，分界线归属也与 App 一致。输入是整个棋盘范围，不是整个屏幕；非边界位置镜像后左右方位相应镜像。局面变化后重新确认动作，不能只复用旧 JSON。
